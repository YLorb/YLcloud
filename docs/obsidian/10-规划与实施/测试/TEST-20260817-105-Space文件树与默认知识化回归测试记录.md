# Space 文件树与默认知识化回归测试记录

## 1. 测试范围

- 分支：`dev`
- 环境：Windows 10 + Docker Desktop
- 数据库：隔离测试库 `ylcloud_space_test`，未对正式/开发库 `ylcloud` 执行写入
- 服务：Frontend、YLcloud App、MySQL、MinIO、Qdrant、RabbitMQ、Model Service、Document Parser、Sandbox Service
- 主链路：注册 → 默认 Personal Space → Space 文件上传 → 默认知识化 → DOCX 解析 → Embedding → Qdrant → RAG 查询 → 知识画像 → 异步删除与跨存储清理

## 2. 回归中发现的问题与解决方案

| 问题 | 根因 | 解决方案 | 验证 |
|---|---|---|---|
| 默认 Personal Space 上传返回“配额账户不存在” | 注册流程创建了 Personal Space，但只为 TEAM Space 注册配额账户 | 创建默认 Personal Space 时同步调用 `QuotaService.registerTeam`，容器类型仍由 Space 自身区分 | `SpaceLifecycleServiceTest` 与 P0 上传通过 |
| Java 调用模型服务返回 401 | Python 模型服务严格要求 JWT Header 包含 `typ=JWT`，JJWT 默认只输出 `alg` | 统一 `ServiceJwtIssuer` 显式写入 `typ=JWT`，增加跨语言 Header 契约测试 | 模型 Embed/Rerank/RAG 实际调用通过 |
| P0 从错误数据库读取解析结果 | 应用使用 `ylcloud_space_test`，脚本却读取 MySQL 容器默认数据库 `ylcloud` | 从应用容器 `SPRING_DATASOURCE_URL` 提取数据库名并校验标识符 | DOCX 解析器断言得到 `docx-structured` |
| P0 使用旧 Space 删除接口 | 删除已升级为预览确认和异步清理，旧脚本仍发送无 Body DELETE | 先调用 `deletion-preview`，再携带名称、令牌、节点版本和过期时间确认删除 | MinIO/Qdrant/数据库最终均清零 |
| 关闭知识画像后的断言错误 | 现行设计保留可审计的 `SKIPPED / PROFILE_SKIPPED_DISABLED` 任务 | 验收改为验证明确跳过状态及终止原因 | P0 通过 |
| 审核测试绕过版本模型直接改画像表 | 当前审核对象是不可变画像版本，直接修改主表不会产生待审候选版本 | 验收使用公开 API 验证人工编辑生成的活动版本与幂等审核；候选激活由 `KnowledgeProfileAssetLifecycleTest` 覆盖 | 审核状态 `APPROVED`，审计含 `PROFILE_EDIT` |
| 增量终止原因被成功收尾覆盖 | `finishAsync` 无条件把原因改写为 `PROFILE_COMMITTED` | 成功任务保留已有增量终止阶段/原因；失败任务仍覆盖为真实失败原因 | `SOURCE_SNAPSHOT_SYNCED`、`UNCHANGED_DOCUMENT` P0 断言通过 |
| 一致性维护与默认知识化并发时领域任务长期停留 RUNNING | 文档一致性版本变化使统一任务成为 `SKIPPED_STALE`，领域任务未同步收敛 | 捕获 `StaleTaskException` 后把领域任务收敛为 `SKIPPED / RESOURCE_VERSION_STALE` | 隔离库实测领域任务不再残留 RUNNING |
| 资源版本变化可能让默认知识化永久跳过 | 旧任务收敛后没有按文档最新版本继续知识化 | 旧任务收敛后幂等创建并分发最新文档版本的替代知识任务 | 维护竞态后可继续生成知识画像；最终 P0 成功 |

## 4. 已知非阻断告警

1. Qdrant Java Client 1.17.0 与服务端 1.15.4 存在版本兼容告警。当前功能测试通过；解决方案是后续将两者调整到小版本差不超过 1 的组合，并重跑向量索引与检索回归。
2. 当前 Flyway 版本仅声明验证至 MySQL 8.1，而测试容器为 MySQL 8.3。迁移和测试均通过；解决方案是升级 Flyway 到明确支持 MySQL 8.3 的版本后重跑空库迁移、存量升级和回滚演练。
3. Maven 编译报告 `WorkflowHttpClient` 使用已弃用 API。当前不影响运行；解决方案是单独替换对应 API 并启用 `-Xlint:deprecation` 做精确收敛。

## 5. 结论

Space 文件树、默认知识化、跨语言模型认证、增量画像、RAG 检索以及异步删除主链路已达到本轮回归放行条件。Sandbox 仍只在文件预检和 Agent 等受控执行场景按需创建任务容器，常驻的是调度服务，不是每个任务的执行容器。
