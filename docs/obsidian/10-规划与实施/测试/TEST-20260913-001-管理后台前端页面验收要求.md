# 管理后台前端页面验收要求

## 1. 交接门禁

实现 Agent/LLM 必须为 TASK-20260913-001 至 TASK-20260913-008 生成完整测试用例，执行适用测试并创建独立测试记录。任一管理路由仍使用通用占位页、模拟操作未标识为非持久化、AdminRoute 可被普通用户绕过、必选测试失败或生产构建失败时，相关任务只能标记 `pending-verification`。

## 2. 必选测试范围

### 2.1 共享骨架与 Mock 数据源

1. `AdminDataSource` 查询、分页、排序、筛选和命令类型保持稳定，页面不直接依赖 `fetch` 或 `api.ts`。
2. 默认返回空数据；测试可注入固定 fixture、未知枚举、缺失字段和错误。
3. Mock 无随机延迟/失败，不读取真实环境数据，不发起网络请求。
4. 创建、编辑、删除、启停等命令只改变当前 Provider 生命周期内状态；重新挂载后恢复空数据。
5. loading、ready-empty、ready-data、error、editing、confirming、submitting、succeeded、failed 均有确定性测试。
6. 重复提交被禁用；模拟失败不修改原集合；删除最后一项后页码回到有效范围。

### 2.2 路由与页面结构

| 路由 | 专项检查 |
|---|---|
| `/admin/dashboard` | 时间范围、0 值指标、空趋势图、系统状态、最近活动、快捷入口 |
| `/admin/settings` | 八类标签、字段类型、脏状态、Secret 掩码、保存/放弃、维护确认 |
| `/admin/fs` | 四类标签、全文搜索条件、结果/证据、图标与浏览应用表单 |
| `/admin/storage` | 策略筛选/详情/表单、备份统计/历史/详情/恢复校验 |
| `/admin/nodes` | 状态指标、负载/容量、节点详情、启停和维护确认 |
| `/admin/user-groups` | 组搜索/分页、权限矩阵、配额、系统组保护、删除冲突 |
| `/admin/user-list` | 用户搜索/筛选、创建/编辑、状态、归组、权限覆盖、当前账号保护 |
| `/admin/file-list` | 文件筛选/分页、格式化、详情、导入表单、删除确认 |
| `/admin/shares` | 分享筛选/分页、有效期、详情、撤销确认 |
| `/admin/tasks` | 任务筛选/分页、状态、详情时间线、重试/取消/清理确认 |
| `/admin/orders` | 订单筛选、整数金额格式化、详情和状态操作 |
| `/admin/events` | 系统事件/安全审计标签、筛选、载荷转义、详情和留存设置 |
| `/admin/reports` | 举报筛选、证据摘要、详情、分派、驳回和处置确认 |
| `/admin/oauth` | 应用筛选、表单、Scope、回调地址、Secret 单次展示、启停/删除确认 |

每条路由必须测试默认空数据、有数据 fixture、数据源错误、直接 URL 访问、侧栏导航、标题映射和浏览器刷新。不允许用快照存在本身代替行为断言。

### 2.3 表单、筛选与边界

- 必填、长度、数值范围、邮箱、URL、金额、日期区间和交叉字段校验。
- 过滤后无结果与数据源为空的文案区分；清除筛选恢复原集合。
- 未知枚举、空可选字段、超长名称/UUID/错误/事件载荷、零金额、无期限和无所有者安全展示。
- 弹窗取消不修改数据；关闭后焦点回到触发按钮；Escape 和遮罩行为与危险操作语义一致。
- URL 只保存非敏感 tab/page/sort/filter；业务记录、Secret 和表单草稿不进入 URL 或持久化存储。

### 2.4 回归、安全与隐私

- 普通用户和未登录用户不能进入 `/admin`；前端门卫行为保持现有约束。
- 页面、fixture、DOM、控制台和错误提示不包含真实用户名、密码、JWT、API Key、OAuth Secret 或生产地址。
- 事件载荷、举报证据、文件名、OAuth 回调地址均通过 React 文本转义，不使用不安全 HTML。
- 所有页面常驻可感知的“演示模式”提示；所有成功 Toast 明确说明未保存到服务器。
- 管理后台不得发出真实管理写请求；为网络层设置 spy，发现写请求立即失败。
- `/files`、`/spaces`、`/knowledge`、`/assistant`、`/tasks`、`/account` 的导航和核心首屏不因 AdminLayout 改造回退。

### 2.5 可访问性、响应式与视觉

- 使用键盘完成侧栏导航、标签切换、筛选、表格行操作、弹窗提交/取消和详情关闭。
- 页面只有一个主标题；输入有 Label；图标按钮有可访问名称；状态不只依赖颜色。
- 弹窗打开时焦点进入，关闭时恢复；移动侧栏具有焦点和关闭入口；skip link 可用。
- 在 320、768、1024、1440 像素宽度检查布局；主操作不被裁切，表格只在容器内横向滚动。
- 浅色和深色主题分别检查文本、边框、状态色、选中态和危险提示；reduced-motion 下无强制动画。
- 对 14 个页面至少保留桌面空状态截图；Dashboard、Settings、Events、OAuth 另保留有数据/弹窗截图；对移动端保留 Dashboard、Users、Tasks、Settings 截图。

- 若新增依赖，补充版本兼容、许可证、包体积和供应链核验；当前方案禁止无审批新增依赖。

1. 14/14 路由使用专属页面，0 个管理路由引用 `PlaceholderPage`，0 处“敬请期待”。

6. 参数设置、文件系统、存储策略保持独立；审计、备份、维护分别位于事件、存储策略、参数设置。
