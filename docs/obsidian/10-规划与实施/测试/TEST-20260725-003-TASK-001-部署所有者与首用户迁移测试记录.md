## 环境与前置条件

- Windows 10 用户 `Win10` 启动 Java 验收实例和 Docker Desktop。
- Docker MySQL 8.3，应用 Spring Boot 3.3.5、Java 17。
- Maven 使用工作区本地仓库 `.m2repo`。
- 隔离数据库：`ylcloud_task001_test`、`ylcloud_task001_history`、`ylcloud_task001_concurrency3`。

## 缺陷与修复

首次并发复现发现两个事务在取得注册行锁前读取站点配置，MySQL `REPEATABLE READ` 因此建立旧快照，第二事务错误地再次判断为首用户并触发唯一约束。已将注册行锁移动为事务第一次数据库读取，并增加调用顺序单元断言；修复后重新使用全新数据库并发验收通过。

真实启动还暴露服务 JWT 发行器和验证器存在多个构造器但未标注注入构造器；已显式标注 Spring 注入构造器并通过启动与 JWT 测试。
