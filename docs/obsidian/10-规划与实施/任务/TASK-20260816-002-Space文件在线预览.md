# Space 文件在线预览

## 目标与依赖

- 目标：在 Space 文件页面直接查看当前文件和历史版本，复用后端已有受权预览能力，不能要求用户先下载文件。
- 上游：REQ-20260725-001、ADR-20260725-001、TASK-20260725-002、TASK-20260725-004；现有 `previewSpaceFile`、`previewSpaceFileVersion` 及流式端点。
- 下游测试：[[10-规划与实施/测试/TEST-20260816-002-Space文件在线预览测试要求]]。

## 修改范围与产物

1. 在 Space 文件列表为非目录项增加明确的“预览”操作，并允许从文件名进入预览；保留下载和版本操作。
2. 提供统一预览面板或对话框，支持当前后端契约已有的文本、图片、PDF、音频和视频类型；展示文件名、类型、大小、加载态、错误态和下载入口。
3. 文本以纯文本方式安全渲染；图片保持比例；PDF、音频和视频使用浏览器原生安全能力并提供不可播放/不可嵌入时的降级提示。
4. 版本历史为每个版本增加预览入口，调用版本预览契约，不得错误预览当前版本内容。
5. 不支持格式、文本过大、对象缺失、流式中断和服务错误均提供明确提示，用户仍可在有权限时下载。
6. 每次预览元数据与流请求都必须由后端校验当前成员关系、目标文件/版本归属和有效状态；前端隐藏按钮不构成安全边界。
7. 复核流响应的 `Content-Type`、`Content-Disposition`、`X-Content-Type-Options`、缓存和嵌入策略，避免 HTML/SVG 等主动内容在主应用同源上下文执行。
8. 预览器支持键盘关闭、焦点管理、可读错误提示及桌面/窄屏布局，不以仅悬浮交互承载关键操作。

## 不包含

- Office 文档在线转换、协同编辑、批注或全文搜索高亮。
- 为不支持格式新增服务端转码基础设施。
- 创建公开分享链接或绕过 Space 权限的临时公开地址。

## 验收标准

- 具备 Space 读取权限的成员可从文件列表预览支持类型的当前文件，并从版本历史预览指定版本。
- 文件移出、版本失效、成员退出或权限撤销后，新的元数据和流式请求立即拒绝；已复制 URL 不能绕过授权。
- 文本、图片、PDF、音频和视频有正确渲染或明确降级；不支持格式不伪装成空白成功。
- 预览失败不影响文件下载、知识状态或版本数据，关闭预览后返回原列表上下文。
- 主动内容不能在 YLcloud 主应用上下文执行脚本，响应头和前端渲染方式满足安全测试。

## 测试、风险与回滚

- 实现阶段必须覆盖预览类型分派、权限负例、文件/版本归属、响应头、XSS/内容嗅探、流式失败、前端组件、键盘可访问性和浏览器 E2E，并创建独立测试记录回写本任务。
- 风险：预览 URL 越权、主动内容执行、大文件占用浏览器内存、媒体兼容差异。
- 回滚：可关闭前端预览入口并保留下载；不得削弱后端已有权限检查或破坏现有 API 契约。
