## 安全负例

- 非管理员不能使用收到授权查询接口。
- 用户不能授权其他用户的私人资源。
- 非实际 Space OWNER（包括 Space ADMIN）不能创建 Space 管理员授权。
- 普通 ADMIN 的 READ 授权不能用于分享、修改、删除或其他副作用。
- API Key/系统任务主体始终绑定 userId，统一授权不会因主体类型扩大资源权限。
