- 目标/需求：以 `/api/v1` 覆盖普通用户文件、Space、知识、Assistant 和 Agent 核心能力；无版本路径走最新版；旧版本30天后只读。
- 依赖/输入：TASK-007；现有 Controllers/DTO/VO、`WebConfig`。
- 修改范围/产物：版本化门面、统一错误/分页/幂等契约、版本策略设置、只读门禁和 OpenAPI 文档。
- 不包含：管理员与部署运维 API；第二个真实主版本。
- 验收：v1 同主版本兼容；无版本行为有明确响应头；过渡期结束所有副作用请求拒绝、读取继续；生产客户端可固定版本。
- 测试/通过：契约、兼容、认证、幂等、大小限制和端到端测试通过。
- 风险/回滚：双路由漂移；版本门面复用同一业务服务并执行契约快照。
- 回写：已交付 `/api/v1` 版本门面、`/api/open` 最新版别名、API Key 独立鉴权、统一响应/错误/分页/幂等契约、版本只读门禁与 `docs/openapi-v1.yaml`。开放接口覆盖文件列表/上传/目录创建/移动/回收站删除、Space 列表与知识查询、Assistant 会话与查询、Agent 查询；Agent 请求把经认证的 Key ID 固化进 Workflow 权限快照，客户端输入无法伪造。未暴露管理员、部署运维、永久删除、分享或成员管理能力。V40 新增 v1 只读时间、30 天兼容期和最大分页策略。Win10 Docker/MySQL 实测 v1 与别名 200、JWT 冒充 401、只读 Key 写入 403、目录幂等回放同一 ID、非法 JSON 400、版本只读写入 410 且读取 200，临时 Key 已撤销、只读配置已复原。
