# 节点配对控制面

- 目标：为无 Web UI 的同版本 YLcloud 从机建立真实通信测试、绑定、解绑和连通状态查询。
- 前置与输入：TASK-20260913-009；现有部署配置、ADMIN 权限服务、服务间安全模式、节点页面。
- 产物：主机 `admin_node` 迁移、从机受保护的身份/版本/挑战响应接口、管理员探测/绑定/查询/复检/解绑 API、端点限制和凭据轮换策略。
- 不包含：存储策略选址、跨节点实际读写、从机 Web UI、任务调度/容量/负载遥测。
- 验收：未通过真实通信/版本/身份校验不得绑定；同 nodeId 重复绑定幂等且不能劫持他人端点；解绑只断开关系不删元数据或实体；离线状态来自真实复检。
- 测试：单机受控从机集成、假节点/重放/SSRF/明文泄露、超时、版本不符、并发绑定、ADMIN/USER 权限、审计及恢复绑定；通过才完成。
- 风险与回滚：私网探测可造成 SSRF，必须目标限制/TLS/短期凭据；可关闭配对入口，保留已绑定记录供后续恢复。
- 回写：实现 Agent 生成完整用例和独立记录并回写状态；下游 [[10-规划与实施/测试/TEST-20260913-002-管理后台真实API与节点绑定测试要求]]。
