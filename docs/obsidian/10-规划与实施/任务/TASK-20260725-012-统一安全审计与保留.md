# 统一安全审计与保留
- 目标/需求：统一记录权限、Key、所有者访问、高风险 Tool、导出、注销、备份和恢复；默认7天、可配置永久。
- 依赖/输入：TASK-001/002/006/007/009/010/016/017。统一审计覆盖任务人工重试/取消、DLQ 处置、保留清理及部署所有者越权访问。
- 修改范围/产物：不可变审计事件模型、统一写入器、查询/导出权限、保留清理任务和敏感字段脱敏。
- 不包含：外部 SIEM 产品集成。
- 验收：关键动作成功/失败均有主体、目标、结果、时间和 Trace；业务操作者不能篡改；永久保留不清理。
- 测试/通过：覆盖率、权限、脱敏、保留边界、批量清理和故障不阻断关键安全拒绝测试通过。
- 风险/回滚：日志含敏感正文；字段白名单和脱敏，停用非关键审计查询不停止写入。
- 回写：记录事件目录、保留执行和抽样证据。
- 测试：[[10-规划与实施/测试/TEST-20260725-001-统一知识平台实施测试要求]]

## 实施内容

### 数据库迁移 (V49)
- 新建 `security_audit_event` 表：不可变审计事件模型
  - 支持 SUBJECT/TARGET/ACTION/RESULT/TRACE 完整记录
  - `retention_policy` 字段区分 STANDARD（可清理）和 PERMANENT（永不清理）
  - 压缩行格式，优化存储
- 新建 `audit_retention_config` 表：保留策略配置
  - DEFAULT: 7天
  - SECURITY_CRITICAL: 永久保留
  - COMPLIANCE: 90天

### 后端实现
- `SecurityAuditService`：统一审计写入器
  - `record()`: 标准审计记录
  - `recordCritical()`: 安全关键事件（永久保留）
  - `recordSuccess()/recordFailure()/recordDenied()`: 便捷方法
  - 字段白名单和正则脱敏（password/secret/token/key等）
  - 审计写入失败不阻断业务流程
- `SecurityAuditMapper`：审计数据访问
  - 按类型/主体/目标/Trace查询
  - 仅清理 STANDARD 保留策略事件
  - PERMANENT 事件永不清理
- `SecurityAuditController`：管理API (`/api/admin/audit/*`)
  - 审计查询
  - 统计信息
  - 保留配置管理（永久配置不可降级）
- 定时清理任务：每天03:00执行，批量清理过期STANDARD事件

### 安全特性
- 不可变设计：应用层无 UPDATE/DELETE 接口
- 脱敏：自动移除/掩码敏感字段
- 永久保留：SECURITY_CRITICAL 事件不受清理影响
- 故障隔离：审计写入异常不阻断关键安全拒绝
