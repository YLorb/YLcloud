# 灰度发布、降级与回滚
- 目标：本轮实现并在本地 Compose 演练 Plan shadow、Retrieval shadow、feature flag、降级和回滚机制，保留 Java 当前 Context 降级链；未来具备环境后再执行白名单和全量生产发布。
- 依赖：TASK-001–011。
- 产物：feature flag、shadow 差异日志、白名单、开关审计、降级原因枚举、发布/回滚手册。
- 不包含：生产部署、真实白名单灰度和全量切流。
- 验收：本地 Shadow 不影响回答；开关可在不回滚数据库的情况下停止新 Run；普通回答降级有标记；高风险请求不降级执行；测试报告不得声称已完成生产灰度或可在无审查情况下直接上线。
- 风险/回滚：双链行为不一致；固定基线集、统计差异，一键关闭 Workflow。
- 回写：每阶段样本数、指标、门禁、风险接受和回滚演练证据。
