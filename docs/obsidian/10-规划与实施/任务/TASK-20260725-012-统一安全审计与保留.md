# 统一安全审计与保留
- 目标/需求：统一记录权限、Key、所有者访问、高风险 Tool、导出、注销、备份和恢复；默认7天、可配置永久。
- 依赖/输入：TASK-001/002/006/007/009/010/016/017。统一审计覆盖任务人工重试/取消、DLQ 处置、保留清理及部署所有者越权访问。
- 修改范围/产物：不可变审计事件模型、统一写入器、查询/导出权限、保留清理任务和敏感字段脱敏。
- 不包含：外部 SIEM 产品集成。
- 验收：关键动作成功/失败均有主体、目标、结果、时间和 Trace；业务操作者不能篡改；永久保留不清理。
- 测试/通过：覆盖率、权限、脱敏、保留边界、批量清理和故障不阻断关键安全拒绝测试通过。
- 风险/回滚：日志含敏感正文；字段白名单和脱敏，停用非关键审计查询不停止写入。
- 回写：记录事件目录、保留执行和抽样证据。
