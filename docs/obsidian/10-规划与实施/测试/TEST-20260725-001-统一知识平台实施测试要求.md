## 必选测试范围

1. **单元测试**：身份/资源/动作授权、所有状态机、Scope 交集、风险等级、幂等键、配额计量、时间窗口、签名、脱敏和备份状态。
2. **数据库集成**：MySQL 唯一约束、行锁、并发首注册、OWNER 转让、一次性授权消费、月度配额和 Flyway 历史数据迁移。
3. **跨存储集成**：MySQL、MinIO、Qdrant 在上传、移出 Space、注销删除、备份与恢复中的一致性和补偿。
4. **API 契约**：JWT/API Key 认证，`/api/v1`、无版本路径、旧版本30天后只读，分页、错误码、幂等和大小限制。
5. **安全测试**：跨用户/Space、普通 ADMIN 越权、所有者审计、目录逃逸、Scope 扩大、Key 泄露面、高风险 REST 绕过、未来 Tool 动态风险、Webhook SSRF/DNS rebinding/重定向和敏感数据泄漏。
6. **端到端测试**：首次注册；PERSONAL/TEAM 生命周期；文件进入/移出知识库；Agent 低/高风险授权；Key 创建与第三方调用；Webhook；注销恢复/删除；导出；配额拒绝；审计查询。
7. **并发与故障注入**：重复请求、乱序事件、Worker 重启、数据库死锁、对象存储/Qdrant 不可用、磁盘不足、任务迟到和网络超时。
8. **性能容量**：授权判断、API Key 验证、配额扣减、Webhook Worker、批量清理和备份窗口的 P50/P95、吞吐和资源使用；基线由实现阶段实测记录。
9. **兼容性**：目标浏览器、Docker Compose、MySQL、MinIO、Qdrant、历史 Flyway 数据及旧 API 只读行为。
10. **灾难恢复**：每个候选备份在隔离 Compose 中完整恢复，验证账号、文件抽样、Space/RAG 引用、Qdrant 查询、配置 Secret 和业务健康；演练升级失败后的旧镜像+READY备份回滚。

## 专项通过标准

- 并发首次注册只能产生一个部署所有者和每用户一个 PERSONAL Space。
- 普通 ADMIN 在无授权时读取任何私人内容均返回拒绝；部署所有者成功访问必有审计。
- PERSONAL Space 不变量无法通过直接 API、旧接口或 Tool 绕过。
- 文件移出 Space 后立即不可检索，最终只清理该 Space 派生物。
- 旧逐 Tool Grant 升级后全部无效；高风险开关不能直接授权高风险 REST。
- API Key 明文无法从数据库恢复；撤销、过期和实时用户权限变化立即生效。
- Webhook 可以重复但不丢失最终可投递事件；接收方可用 `eventId` 幂等。
- 注销超过3天只提交一次可重入删除任务；TEAM 引用数据不被误删。
- 相同物理内容只计一次；TEAM 配额与 OWNER 个人配额完全隔离。
- 新备份未通过完整恢复时，上一份 READY 备份始终存在且可恢复。
- 旧 API 兼容期结束后所有副作用操作拒绝，读取结果与权威业务服务一致。
