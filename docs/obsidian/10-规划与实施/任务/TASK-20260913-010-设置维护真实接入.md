# 设置维护真实接入

- 目标：`/admin/settings` 读取/保存已有站点键，接入维护状态和启停命令。
- 前置与输入：TASK-20260913-009；`AdminSettingController`、`MaintenanceController`、`SiteSettingVO` 和前端设置页。
- 产物：仅真实 key 可编辑的字段映射；密钥掩码/不回显；维护状态、原因、二次确认和真实结果提示。
- 不包含：无后端键的会话、验证码、计费、SMTP 或任务队列配置；不得存为前端“真实成功”。
- 验收：刷新后真实设置一致；错误/403 不显示成功；维护模式状态与服务端一致；部署所有者专有限制保持原后端规则。
- 测试：DTO 映射、秘钥不回显、校验/并发、维护开关权限、异常/回归和浏览器链路；通过才完成。
- 风险与回滚：误写配置可能影响注册/服务访问；限定字段、确认与审计，前端回滚不回滚已写值，值恢复需审计操作。
- 回写：实现 Agent 生成完整用例和独立执行记录并回写状态；下游 [[10-规划与实施/测试/TEST-20260913-002-管理后台真实API与节点绑定测试要求]]。
