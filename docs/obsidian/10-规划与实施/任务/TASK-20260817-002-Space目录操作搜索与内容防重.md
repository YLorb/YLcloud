# Space 目录操作、搜索与内容防重

## 目标与依赖

- 目标：补齐 100 层目录不变量、祖先链、重命名、移动、全 Space 搜索和同内容唯一位置。
- 前置：TASK-20260817-001；现有 `SpaceFileController/Service/Mapper`。
- 下游：[[10-规划与实施/测试/TEST-20260817-102-Space目录操作搜索与内容防重测试要求]]。

## 修改范围与产物

1. Flyway 增加 node version、depth、content hash、lifecycle state、内容 guard 和必要索引；生成历史重复报告，不自动合并。
2. 新增 ancestors/search/rename/move/duplicates-report API、DTO 和 VO，严格采用 ADR-20260817-001 契约。
3. 根深度 0；创建/移动结果超过 100 返回 409；历史超深可读但不能继续加深。
4. `parent_id` 为真相，重命名/移动在事务内批量更新节点与后代 depth/path/nodeVersion；拒绝跨 Space、非目录目标、移动环和陈旧版本。
5. Space 搜索服务端分页并返回受权路径；REMOVAL_PENDING/REMOVED 不进入普通结果。
6. 防重在 Sandbox 前取得 guard；相同 UUID 或 SHA-256 返回 409 和已有节点定位，不移动已有节点。

## 不包含

- 历史重复自动治理、文件 ACL、全文内容搜索。

## 验收、测试与回滚

- 100 层、移动环、并发重名/重复内容和跨 Space ID 均被数据库事务约束。
- 搜索覆盖整个 Space且不泄露无权/隔离节点。
- 回滚不删除新增列/guard；应用降版继续读取 ACTIVE 历史节点。
- 实现者生成完整用例和独立记录，完成真实 MySQL 并发与深度测试。
