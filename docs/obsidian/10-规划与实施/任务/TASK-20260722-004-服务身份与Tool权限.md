# 服务身份与 Tool 权限
- 目标：建立 Java ↔ Workflow ↔ Model/Tool 的服务身份、audience、短期 Token、Tool scope 和审计边界。
- 依赖：TASK-001/002。
- 产物：JWT issuer/verifier、密钥轮换/JWKS、scope 检查、服务时钟偏差策略、脱敏日志和诊断审计。
