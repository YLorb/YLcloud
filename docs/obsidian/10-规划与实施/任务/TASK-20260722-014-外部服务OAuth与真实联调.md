# 外部服务 OAuth 与真实联调
- 目标：在首阶段 Mock Tool 稳定后，为真实邮件和日历提供方接入 OAuth 2.0 或其要求的应用凭证，并完成受控沙箱联调。
- 依赖：TASK-004/006/011，以及可用的提供方测试账号、OAuth 应用或沙箱凭证。
- 产物：Provider Adapter、授权/回调/刷新/撤销流程、加密 Token 存储、最小 scope、账号解绑、失败补偿、审计与真实服务沙箱测试报告。
- 不包含：当前首阶段 Mock Tool 验收；在没有测试账号时操作真实用户邮箱或日历；生产全量开放。
- 验收：授权、刷新、撤销和过期恢复通过；邮件/日历真实沙箱调用保持与 Mock 相同 Tool 契约；高风险写操作仍受 `ALLOW_ONCE/ALLOW_SIMILAR` 约束；日志、Trace 和错误响应不泄露 access/refresh token；断开 Provider 后不影响知识问答和其他 Tool。
- 风险/回滚：提供方差异、Token 泄漏和限流；按 Provider feature flag 回退到 Mock/不可用状态，不静默执行真实副作用。
- 回写：Provider、scope、凭证责任人、沙箱账号、限流、测试证据和上线门禁。
