位置：`mini_agent_flow/planner/selector.py`

内容：

### 2. LLM Workflow Generator

位置：`mini_agent_flow/planner/generator.py`

内容：

- `WorkflowGenerator`：根据自然语言 goal 生成 workflow。
- 首次生成后校验，失败时进入 self-repair 循环。
- 支持 `max_repair_attempts` 限制。
- prompt 中包含 Workflow JSON Schema 和允许工具白名单。

验收标准：

- [ ] `python -m mini_agent_flow make --goal "总结 AI Agent 工作流发展趋势"` 能生成合法 workflow。
- [ ] 生成的 workflow 会经过 `WorkflowValidator` 校验，非法工具引用会被拒绝。
- [ ] 使用 DeepSeek 等真实 LLM 时，self-repair 能修复常见的结构错误。
- [ ] `tests/test_workflow_generator.py` 全量通过。
