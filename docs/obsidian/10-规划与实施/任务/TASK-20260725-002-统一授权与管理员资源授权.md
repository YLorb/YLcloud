# 统一授权与管理员资源授权
- 目标/需求：移除 ADMIN 全局数据豁免；统一用户、所有者、API Key 和系统任务主体；普通 ADMIN 仅在用户/TEAM OWNER 显式授权后读取私人资源。
- 依赖/输入：TASK-001；`AccessControlService/Mapper`、`AdminPermissionService`、拦截器。
- 修改范围/产物：`AccessSubject`、资源动作枚举、统一授权服务、管理员资源授权表/API；所有者越权路径与审计钩子。
- 不包含：API Key 创建、审计保留任务。
- 验收：Controller、Service、Tool 均不能绕过授权；授权撤销立即生效；普通 ADMIN 默认跨用户拒绝，所有者允许且留审计。
- 测试/通过：权限矩阵、跨用户/Space 负例、缓存撤销和并发授权测试通过。
- 风险/回滚：漏接入口导致越权；以入口清单和 deny-by-default 门禁验证，失败回滚本阶段代码与迁移。
- 回写：更新权限矩阵、入口清单和安全测试证据。
