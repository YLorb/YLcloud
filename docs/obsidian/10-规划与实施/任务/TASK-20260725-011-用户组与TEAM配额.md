# 用户组与 TEAM 配额
- 目标/需求：扩展用户组配额至存储、文件、Space、API、Token、Agent任务和并发；TEAM 存储使用独立配额；周期用量自然月重置。
- 依赖/输入：TASK-003/004/007；`StorageService`、权限组、物理引用。
- 修改范围/产物：配额策略、TEAM 配额账户、唯一物理内容计量账本、月度用量和对账任务。
- 不包含：支付、订单和自动计费。
- 验收：相同物理内容全局只计一次且归属明确；并发扣减不超卖；解除最后引用释放；外部可查询用量。
- 测试/通过：并发、月界、时区、去重、所有权转移、对账修复和性能测试通过。
- 风险/回滚：账本漂移；周期全量对账可修复，异常时保守拒绝新增资源。
- 回写：记录计量公式、归属规则和对账差异。
- 测试：[[10-规划与实施/测试/TEST-20260725-001-统一知识平台实施测试要求]]

## 实施回写

- Flyway V42 新增用户组配额策略、USER/TEAM 独立账户、自然月用量、物理内容账本、逻辑引用和对账证据；策略维度覆盖存储、单文件、Space、API、模型 Token、Agent 月任务及并发。
- `content_key = 非空文件 hash，否则 uuid:<fileUuid>`。一个物理内容仅有一条账本记录；首个逻辑引用账户承担物理字节，归属引用移除时转给剩余活动引用中 `account_id` 最小者，最后引用解除时删除账本并释放字节。
- USER 和 TEAM 分账。TEAM 创建时继承所有者用户组策略，所有权转移时只迁移策略组，不重写历史使用量或物理引用。
- 月度 API/Token/Agent 用量以 `Asia/Shanghai` 自然月首日为周期键；限额 `0` 表示不限。API、Token 及 Agent 月量/并发均由带上限谓词的单条 SQL 原子更新，失败返回 HTTP 429。
- Agent 终态即时释放并发；每 30 秒按真实 `QUEUED/RUNNING` 消息校正异常残留。每日 03:20 执行物理引用数量、归属、孤儿账本和并发对账，并持久化差异与修复证据。
- Web、开放 API 和管理端均可查询用量；管理端可更新用户组策略并触发对账。
