# RAG E2E Checklist

Use this checklist after starting MySQL, MinIO, Qdrant, model-service, and Spring Boot.

## 1. Create A Space

Create a space through the existing space API or UI. Confirm:

- `spaces` has one active row.
- `space_rag_config` has one active config for the space.
- the current user is a space admin.

## 2. Upload A Text File

Upload a `.txt` file into the space file tree. Confirm:

- `space_file` has a file row with `is_dir = 0`.
- `space_rag_document` is created.
- `space_rag_task` has an `INDEX_FILE` task.

## 3. Wait For Indexing

Poll:

```text
GET /api/space/{spaceId}/rag/tasks
```

Expected:

- `taskStatus = SUCCESS`
- `totalCount = 1`
- `successCount = 1`
- `failedCount = 0`

Confirm:

- `file_rag_chunk` has chunks for the file hash.
- `space_rag_chunk_ref` has active refs.
- Qdrant search returns the chunk when asking a related question.

## 4. Ask A Question

Call:

```text
POST /api/space/{spaceId}/rag/query
```

Expected response:

- `answer` is generated by chat or safe fallback.
- `hitChunkIds` is not empty for a related question.
- `citations` includes `fileName`, `spaceFileId`, `documentId`, `previewUrl`, and `downloadUrl`.

Ask an unrelated question. Expected:

- no unrelated recent chunks are used.
- answer is the configured no-answer response.

## 5. Version Change

Upload a new version or restore an old version.

Expected:

- version operation succeeds independently.
- after transaction commit, a `REBUILD_FILE` task is created.
- if the RAG task fails, version metadata remains committed.

## 6. Delete File

Delete the space file.

Expected:

- `space_rag_chunk_ref` is disabled.
- the document is disabled.
- Qdrant vectors for the `spaceId + spaceFileId` filter are removed.
- asking the old question no longer returns that file as a citation.

## 7. Repair Consistency

Use:

```text
POST /api/space/{spaceId}/rag/vectors/repair
```

Expected:

- Qdrant vectors for the space are cleared.
- active DB refs are rebuilt into Qdrant.
- task progress shows total, success, and failed counts.
