## 已实现的修改

1. **知识库策略配置**：所有者/管理员管理更新期间旧内容可用开关、历史证据开关与保留天数；两个开关默认关闭。增加并发配置校验、变更记录、保留期限调整影响预览与设置 UI。
2. **文件与索引一致性**：增加知识修订、重建意图、不可变 chunk generation；绑定原文件具体对象版本与 SHA-256；通过版本、任务和执行轮次校验约束旧索引提交，保护共享文件及修订引用。
3. **可信回答与引用**：模型分类、结构化结论、确定性校验与逐结论 Judge；事实/知识推断区分，政策缺乏明确依据时拒答；证据 ID、版本、页/段定位与受保护原文读取。
4. **会话与权限**：服务端 answerId 绑定；历史正文及模型上下文重新授权；普通聊天与 Workflow 最终回答使用可信结果，客户端正文或冻结工具输出不能自行成为可信答案。
5. **开放接口与通知**：增加 assistant/agent 查询任务结果的 GET 接口，兼容 `/api/v1` 与 `/api/open`；复核原任务的 Space 与 API Key scope。AGENT_TASK Webhook 只携带任务状态/answerId，读取答案仍经过当前授权。
6. **界面与验证工具**：知识设置、引用原文弹窗、版本/页码与回答状态展示；合成评测题集、指标脚本、浏览器夹具；CI 增加后端/前端验证门禁。

新增数据库迁移：V58、V59、V62、V63。已检查本地 dev 无重复编号；尚未在真实数据库应用这些迁移。
