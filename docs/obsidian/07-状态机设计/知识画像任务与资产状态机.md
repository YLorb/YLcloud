# 知识画像任务与资产状态机

## 任务状态

~~~mermaid
stateDiagram-v2
  [*] --> PENDING
  PENDING --> RUNNING: CAS 抢占
  PENDING --> SKIPPED: PROFILE_DISABLED 或无符合条件文档
  RUNNING --> SUCCESS: 批次完成且结果可持久化
  RUNNING --> FAILED: 执行异常或全部失败
  RUNNING --> SKIPPED: 运行时条件不再满足
  RUNNING --> FAILED: 超时回收
~~~

PROFILE_DOCUMENT 处理单文档，PROFILE_SPACE 是空间批次。活动任务唯一约束和 PENDING→RUNNING CAS 防止同一范围重复执行。

## 流水线阶段

常见 stage 包括 PROFILE_PENDING、生成、PROFILE_VALID、PROFILE_NEEDS_REVIEW、PROFILE_SUCCESS、PROFILE_FAILED。stage 用于观测本次运行，不等同于资产审核状态。

## 画像资产状态

~~~mermaid
stateDiagram-v2
  [*] --> GENERATED: 模型生成并解析
  GENERATED --> APPROVED: 校验通过或人工批准
  GENERATED --> NEEDS_REVIEW: 质量问题不可自动安全修复
  NEEDS_REVIEW --> APPROVED: 人工审核
  NEEDS_REVIEW --> FAILED: 拒绝或处理失败
  APPROVED --> APPROVED: 编辑/分类/恢复形成新版本
~~~

当前实现包含 APPROVED、FAILED、NEEDS_REVIEW 等语义，并通过版本表和审计日志记录修改。未来若引入正式发布模型，应增加 CANDIDATE、PUBLISHED、SUPERSEDED，而不是复用任务 SUCCESS。

## 开关状态

knowledgeProfileEnabled 是配置开关，不是任务状态。默认 true；RAG 完成后读取数据库最新值。关闭：

- 不执行生成；
- 不创建画像版本或画像事件；
- 不删除已有画像；
- 保存明确 SKIPPED/PROFILE_DISABLED 终态；
- 不影响 RAG_READY。

## 批次结果

任务保存 total/success/failed。零符合条件文档是 SKIPPED/NO_ELIGIBLE_DOCUMENTS，不是 SUCCESS/0/0；画像失败数不应被历史累计值污染。前端根据当前批次终态显示“成功 X 个文档、失败 Y 个文档”。
