# Share-link 实施方案

来源：REQ-20260920-001。需求于 2026-09-20 确认；本方案已定稿为开发交接，功能仍 pending。内部服务名、字段名和接口名为实施设计，不宣称已有实现。

## 1. 背景与目标

把现有公开分享替换为有期限、下载额度、密码或强制下载选项的统一链接体系，覆盖个人与空间。

## 2. 用户、场景与业务价值

编辑者创建，创建者/admin 管理，接收者通过卡片或直接下载获取内容。管理员可追溯访问，普通用户查看自己的累计下载次数。

## 3. 需求范围与非目标

范围按 R01–R14。仅分享访问禁止预览，个人/空间正常登录预览保留。无多选分享、目录展开、子文件下载、自动碰撞重试、点击限制、网关/IP 服务接入。

## 4. 验收标准

全部 R01–R14 必须满足；最后一个名额并发不超发；短码冲突不串文件；过期和未知码 HTTP 200 提示；旧 API 无旁路；30 天清理不改变累计值。任务下游 TEST-20260920-001 定义具体门禁。

## 5. 现状与证据（2026-09-20 只读核验）

- FileService.shareFile 当前使用 MODIFY 权限，按 user_file_id 与 owner_id 复用；FileShareMapper 未回填自增主键，新增方案必须回填。
- FileShare/FileShareMapper 与 db/permission-share.sql 使用 file_share，字段没有期限、额度、密码；ShareCodeUtil 当前 SecureRandom 生成 8 位码，字符表为 0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ。
- ShareController 位于 /api/share，包含元信息、download、preview、stream；WebConfig 当前匿名放行 /api/share/**。
- App.tsx 使用 /share/:shareCode，FilesPage 调用 api.shareFile；PublicShareView 递归目录并内嵌内容，均需替换。
- SpaceFileAccessService.requireNodeAction：非只读成员也受节点创建者约束，不能简单按“空间成员”开放分享；当前 SpaceFileAction 无 SHARE。
- admin SharesPage 使用 AdminCollectionPage/config；新功能必须接真实分享数据，禁止沿用模拟累计数。
- pom.xml 为 Java 17；cloud-server 已有 MySQL/MyBatis/Flyway 依赖；清理任务可衔接 CleanupMaintenanceTaskHandlers。
- 当前分支实际为 dev，含未提交的预览工作；本轮不改其内容、不切分支。后续编码前重新检查分支与工作树。
- 不属于故障根因诊断；未运行数据库、应用或测试，因此无运行成功证据。

## 6. 约束、假设与未决事项

产品未决事项为零。实现细化：时刻使用带时区输入并归一到 UTC，null 表示无限；正整数使用 64 位计数，超过存储范围报验证错误。固定选项可包含永久/1/7/30 天，自定义为最终到期时刻。无密码复杂度规则，开启不可空，不静默截断密码。
文件夹变化需要记录替换事件，不能只比较下载当时 UUID。实现时加入单调内容代次或持久排除记录；这是满足 R09/R10 的机制，不是新增预览或版本分享。

## 7. 候选方案比较

评价顺序：满足需求、安全、正确性、维护、交付、性能、成本、团队适配、锁定。

| 方案 | 取舍与结论 |
|---|---|
| 两 ID Base62 拼接截 8 位补 a | 用户指定；简单但可预测、碰撞无法消除；唯一约束拒绝冲突，不自动重试。 |
| 完整拼接可变长 | 保留信息但不符合固定 8 位，未选。 |
| 随机/散列 8 位并重试 | 可降低结构性碰撞，但用户暂不选择，进入 TODO。 |
| 流式 ZIP | 不缓冲整个文件夹，适合大文件；传输中故障会造成不完整 ZIP，本方案采用。 |
| 先落盘完整 ZIP | 可提前发现打包错误，但增加临时存储和清理成本，本期不采用。 |

## 8. 选定架构决策

MySQL 为记录与计数的事实来源；Java 服务集中授权与有效性判定；对象存储只由后端读取；React 负责弹窗/卡片；不增加 Redis。
短码必须持久化，按大小写唯一查找，绝不尝试反解。字符表沿用现有 ShareCodeUtil；算法版本记为 1。
冲突回滚整个创建事务，返回“短链接冲突，创建失败”；自增号空洞正常，不重置序列，不覆盖任何旧记录。

## 9. 模块与关键流程

创建：认证身份 → 目标编辑权限 → 锁定稳定目标行 → 找同创建者有效链接 → 复用并按提交条件修改，或插入取 ID → 编码/补位/截断 → 写唯一短码 → 提交 → 前端组合 origin。
同对象创建锁用于避免并发重复建记录，不是请求限流；禁止客户端自行传 creator_id。
访问：页面 open → 可选认证、记录访问 → 有效性判断 → 密码门或卡片/强制下载。
下载：校验密码凭据及有效条件 → 短事务原子批准/计数 → 提交 → 单文件或 ZIP 流，传输期间不持有数据库锁。
管理修改：创建者/admin → 锁链接 → 修改条件保留 code、download_count；撤销独立永久标记。创建者失去编辑权限仍能管理自己链接，但不能借修改绕过源文件有效性检查。

## 10. 接口、数据模型与状态

### 数据表（设计名）

| 表/字段 | 语义 |
|---|---|
| share_link.id / creator_id | BIGINT 主键/创建者，创建者来自认证 |
| short_code / algorithm_version | 8 位 ASCII，区分大小写唯一；版本 1 |
| source_type / source_id / space_id | PERSONAL/SPACE、归属记录 ID、可空空间 ID |
| file_uuid / content_revision | 绑定内容 UUID 与替换代次；目录以节点身份为准，不能把目录当存储对象 |
| expires_at / max_downloads / download_count | null 永久/null 无限/累计批准次数，默认 0 |
| password_enabled / password_hash | 关闭时 hash 为 null；开启非空哈希，不可读回 |
| force_download / revoked_at / replaced_at | 强制下载、手动撤销、内容被替换失效时间 |
| created_at / updated_at / version | 创建/修改时间及并发更新版本 |
| share_link_visit | id、link_id 可空、requested_code、user_id 可空、匿名 ip、city 默认“-”、visited_at、outcome |
| 目录排除关联或内容代次记录 | 按源节点标识记录替换事件，支持根链接和子树判断；若现有版本机制可复用则避免重复表 |

索引：short_code 唯一；creator_id+source_type+source_id+file_uuid 复用查询；creator_id+created_at 列表；visited_at 清理；link_id+visited_at 管理日志。请求短码须限长度、清除控制字符再记日志，不存密码、令牌。
回收站与权限丢失为派生状态，不写成永久撤销；替换与手动撤销持久记录。状态判定依次检查存在、撤销、替换、源对象与权限、期限、额度。对外合并为 EXPIRED；管理员内部可展示原因。

### 拟定接口

| 方法/路径 | 行为 |
|---|---|
| POST /api/share-links | 认证创建/复用；sourceType/sourceId/spaceId、期限模式、额度、密码设置、forceDownload |
| GET /api/share-links | 仅自己的链接，分页，显示累计次数 |
| PATCH /api/share-links/{id} | 创建者/admin 修改；省略密码保留哈希，关闭清空，更换重新哈希；时间区分 EXTEND 与 SET |
| POST /api/share-links/{id}/revoke | 撤销，重复调用保持撤销 |
| POST /api/public/share-links/{code}/open | 每次页面打开记录一次访问，返回 EXPIRED/PASSWORD_REQUIRED/READY 及页面作用域凭据 |
| POST /api/public/share-links/{code}/verify | 密码请求体，不进 URL；验证后返回当前页面凭据，更新本次访问结果 |
| POST /api/public/share-links/{code}/download | 批准并直接流式下载；密码凭据放表单请求体，不进 URL |
| GET /api/admin/share-links | 管理员真实全量分页 |
| GET /api/admin/share-links/{id}/visits | 管理员单链接访问日志 |
| GET /api/admin/share-link-visits | 管理员全局日志，包括未知短码记录 |

页面凭据为签名短时凭据，绑定 code、访问 ID、链接 version，仅存页面内存，不存浏览器持久存储；修改密码/条件后旧凭据不能绕过检查。页面重新打开无凭据，重新输入。其有效时长为内部参数，失效后提示重新验证。
公开接口允许匿名但尝试解析可信登录身份；不能把整个 /api/share-links 放入匿名白名单。失效 HTTP 200 的业务状态与现有 Result 包装对齐；管理操作继续使用正常鉴权错误语义。
下载用原生 form POST 导航接收 attachment，避免 fetch Blob 缓存大文件；无效则返回 HTML 提示页 HTTP 200，不能 attachment 保存错误页。HEAD/open/verify 不扣额度。强制下载只自动发起同一下载接口，不新增绕过路径。

## 11. 异常、并发与恢复

批准时锁定链接并复验源状态/权限、密码版本、到期与次数，增加 download_count 后提交。修改条件和撤销用相同链接锁；源变更与批准定义一致锁顺序/版本校验。批准提交是准入边界；已批准事务后发生到期/撤销不追溯取消。存储无法继续读时终止流，不伪报完成、不退还额度。
不做快速点击去重，不实现共享下载凭据去重；每次独立下载批准都计次。本期不承诺 Range 续传免计次；不广告未实现的 Range 能力。
目录下载按批准时收集有效子项清单，新增在下次下载进入；过滤已删除、越界、无权读取、替换子项。已有子文件按节点替换代次排除；新加入文件若在加入后被替换同样排除，需生命周期变更时维护，不能仅在首次下载时建立基线。空目录生成有效空 ZIP。
ZIP 路径只允许相对规范化路径，处理重名、中文、空目录，禁止 ../ 和绝对路径；流式读取并及时关闭资源。

## 12. 安全、隐私

密码使用带盐的专用密码哈希，复用仓库合适实现前核验长密码行为；不能用普通 SHA/明文或静默截断替代。后端强制 password_enabled 与 force_download 互斥。
公开元信息不返回 children、对象存储路径、预览地址或哈希；原 preview/stream API 必须关闭。
IP 仅信任部署配置的代理链，否则取连接地址；身份必须认证验证，不能采信客户端账号。日志仅 admin，可选认证失败按匿名处理而非信任无效 Token；系统自身故障不可伪装为已登录。
不调用地理服务。日志失败须记录运维错误，不能返回假日志成功；页面访问记录成功前不返回 READY（内部存储错误按系统故障处理，不伪装“文件已过期”）。

## 13. 性能与可观测性

大文件采用流式传输及 ZIP，内存不随文件总字节数线性增长；目录清单使用有界遍历或分批存储，避免整树文件内容加载。并发批准正确性必须验证，即使用户暂无吞吐指标。
记录创建碰撞、批准/拒绝、流失败、日志写失败、清理数量与耗时；访问日志保留不等于下载历史逐条日志。本期只累计下载业务次数。
清理任务每日执行分批删除 visited_at 早于当前时刻 30 天记录；失败可重跑，截止时刻统一 UTC，不能误删边界内记录。

## 14. 兼容、迁移、发布、回滚

1. 编码前核验实际分支、已有改动、迁移版本；新增版本化迁移，不修改已应用 Flyway 文件。
2. 先备份旧表及相关配置，新增结构和新代码，维护窗口封闭旧创建及所有公开读取路径。
3. 新 /s 路由与 API 验证通过后清理旧 file_share 记录；保留空表可供回滚诊断，清记录不等于必须 DROP 表。
4. 旧 /share/* 及 /api/share/* 的元信息/preview/stream/download 全部返回失效，绝不映射到新码；旧创建接口停止创建。
5. 回滚优先回退新 UI/暂停新分享，保留旧入口失效保护；备份仅用于恢复数据，不自动恢复旧链接。备份演练和清理操作由后续执行，当前不运行。

## 18. 风险与接受记录

2026-09-20 用户接受：8 位截断补位碰撞时创建失败，无自动重试；本期不做快速点击/网关限流；地点暂为“-”。可预测短码不具备随机秘密强度，无密码链接可被猜测；截断可能完全丢掉用户段。其他已知限制：批准后断流仍计次、流中失败可能留下损坏 ZIP，不能宣称客户端保存成功。
延期项在 ISS-20260920-001 记录，后续调整算法不得悄然改变本期约定。

## 19. 官方来源与核验日期

2026-09-20 已核验：

## 20. 实际落地记录（2026-09-20）

采用 ShareLinkService/ShareRepository/ShareCrypto/ShareLinkController，复用现有个人与空间权限服务。V55 建表与替换修订标记，V56 增加物理内容变更保护并归档清空旧分享。密码使用带盐 PBKDF2；公开凭据使用独立签名用途、15 分钟有效期和条件版本绑定。数据库时间统一 UTC 微秒。批准事务写磁盘清单并固定 MinIO 对象版本，事务外流式传输。前端使用原生下载表单，避免全量 Blob。
