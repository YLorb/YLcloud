# Share-link 需求基线

2026-09-20：用户已确认全部需求并授权产出实施方案。状态 pending 表示功能待实现，不表示需求尚未确认。本轮仅文档规划，未修改功能代码、数据库，未执行测试。

## 目标与原始流程

替换全部现有分享能力。为文件设置条件 → 查询可复用链接 → 复用或新建 MySQL 记录 → 取记录 ID → 生成短码 → 返回当前站点 /s/{短码} → 弹窗展示并复制。旧链接全部失效，旧表记录清理。

## 已确认需求与可验收结果

| 编号 | 规则与通过条件 |
|---|---|
| R01 | 支持个人文件、空间文件及文件夹。有编辑权限可创建；其他编辑者不能修改他人的链接，创建者和管理员可以管理。 |
| R02 | 复用键为创建者与文件归属记录及 UUID；有效链接复用，过期、额度用尽时新建记录。额度属于链接，不属于访问者。 |
| R03 | 短码为 Base62(记录 ID) 拼接 Base62(创建者 ID)，取前 8 位，不足右补 a；冲突创建失败，不自动重试。 |
| R04 | 默认永久，支持固定时长和自定义时间；选择有限时长时原到期时间累加，已过期从当前时间计算，永久转有限从当前时间计算。明确修改旧链接可延长它；再次创建时已过期链接不复用。 |
| R05 | 默认无限下载，可填正整数上限；已批准次数累计保留。批准下载计一次，同一人重复下载也计次，ZIP 一次计一次；降低上限至累计次数以下立即失效。 |
| R06 | 不允许内容预览和文件夹目录浏览；接收者只看文件或文件夹卡片并下载。文件夹仅整体 ZIP 下载，不提供子文件下载入口。 |
| R07 | 密码由用户设置，不设复杂度规则，开启时非空；存哈希，不回显原密码。每次重新打开链接均需输入。 |
| R08 | 可配置强制下载，与密码保护互斥；强制下载不展示卡片。生成弹窗显示短链接和复制选项。 |
| R09 | 删除、失去编辑权限使链接失效；恢复文件或权限后，在未撤销、未过期、额度足够、未被替换时恢复。文件替换使链接失效；关联 UUID 及归属记录。 |
| R10 | 文件夹新增、删除内容反映到 ZIP；被替换子文件排除，不使整个文件夹链接失效。 |
| R11 | 各类失效及不存在的短码：HTTP 200，提示“文件已过期”；已批准的下载允许完成。 |
| R12 | 每次打开均记录访问，包括未知短码、过期、密码未通过；登录者记录账号，匿名记录 IP、地点、时间。管理员独占访问日志可见权限；普通用户可查看自己链接的累计下载次数。 |
| R13 | 地点当前为“-”；访问日志保留 30 天，自动清理更早记录。管理员分享页面接真实接口。 |
| R14 | 当前站点域名生成完整链接；无固定 5 位要求，固定 8 位。大文件需要支持，暂无容量、带宽或并发数字目标。 |

## 澄清修正记录

- 最初“支持文件夹预览”最终修正为不展示目录或内容，只显示文件夹信息；ZIP 下载。
- 初始短码方案最终改为两个 Base62 ID 拼接后取前 8 位、右补 a；用户接受碰撞失败。
- 初始防重复点击诉求最终推迟，本期不限制快速重复请求。
- 用户明确 30/day 清除：按保留 30 天解释，清理超过 30 天记录，不是每 30 天才运行一次。
- 旧链接失效与旧表清理已授权为后续功能范围；本轮未执行。

## 非目标、约束与风险

不引入网关、Redis、外部 IP 服务，不实现自动短码重试、防抖/频率限制、内容预览、文件夹目录浏览、多文件选中分享。
密码保护不是文件加密。截断码可预测、可能碰撞；用户已接受当前规则及失败策略。
数据库清理需有可恢复备份，回滚不能重新开放旧链接。产品未决事项为零；架构内部实现选择在 ADR 明示。
