# 已完成任务

## 总览

当前项目已经完成 Level 1 的主体能力，并完成 Level 2 的规则模板选择版本。

一句话概括：

```text
项目已经能加载 JSON / YAML Workflow，校验结构和工具白名单，执行 start / llm / tool / condition / end，记录 Trace，并支持根据 Goal 从模板库选择 Workflow。
```

## Level 1：人工 Workflow 执行

已完成：

- Workflow JSON Schema。
- Pydantic Workflow 模型。
- JSON Loader。
- YAML Loader。
- 统一 WorkflowLoader。
- WorkflowValidator。
- WorkflowContext。
- VariableResolver。
- ToolRegistry。
- 内置 `echo` 和 `mock_search` 工具。
- MockLLM。
- SequentialWorkflowExecutor。
- Condition Node。
- LLM / Tool 节点 Retry。
- TraceRecorder。
- 顶层 outputs 最终输出机制。
- CLI `run` 命令。
- Level 1 JSON / YAML 示例。

当前可运行命令：

```powershell
python -m mini_agent_flow run examples/level1_manual_workflow.yaml
python -m mini_agent_flow run examples/level1_manual_workflow.json
```

## CLI 能力

已完成命令：

- `run`：执行人工定义 Workflow。
- `select`：根据 Goal 从模板库选择 Workflow 并执行。

支持参数：

- `--provider mock|deepseek`
- `--model`
- `--templates`
- `--trace / --no-trace`

CLI 使用 Typer 实现命令解析，使用 Rich 输出结果。
