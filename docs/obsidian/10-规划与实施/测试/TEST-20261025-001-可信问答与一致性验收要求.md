# 可信问答与一致性验收要求

来源任务：TASK-20261025-001，T01—T16。本文规定范围与通过标准；已执行项目及尚未验证项目另见 [[10-规划与实施/测试/TEST-RUN-20261025-001-可信问答实施验证]]。单元/契约测试通过不能替代真实存储、模型和迁移验收。

## 环境及数据

- 使用合成且可核验的数据，不复用生产用户资料；至少两个 Space、个人原件、所有者/管理员/成员/外部用户和共享物理对象。
- 构造多个内容修订、不同生效日期/适用条件、同文件不同版本和版本缺失历史消息。
- 文档覆盖中文 PDF、PPT、文本、表格、否定句、单位换算、脚注、相似但不支持结论的干扰资料。
- 隔离 MySQL、MinIO、Qdrant、MQ、服务端口、模型配置和输出目录；记录版本与配置。真实存储测试不能被内存 Mock 代替。
- 真实模型质量测试与契约 Mock 分开报告；模型生成器和 Judge 的判定均需与独立人工标签比对。

## 必须通过的确定性边界

| 范围/任务 | 通过标准 |
|---|---|
| 配置 T02/T13 | 所有者与管理员配置；成员拒绝；默认两开关关闭；历史开启需期限；过期配置写入冲突；旧请求不清空新字段 |
| 修订/调度 T03/T04 | 当前修订不可变；上传回滚保持旧状态；提交后故障仍可恢复重建；共享文件更新不改变其他逻辑引用内容 |
| 构建 T05 | 重复投递幂等；旧轮次/旧修订拒绝提交；旧任务的向量写入及清理不破坏新构建；数量与身份均核对 |
| 删除 T06 | 删除提交后新检索/预览/下载/历史读取不可泄露；删除过程中旧任务完成不能复活；恢复资源不得复用旧代次 |
| 保留 T07 | 不同 Space 权益独立；到期逻辑不可访问；延长期限与回收串行化；新引用不绑定回收占用对象；个人原件保留 |
| 定位 T08/T09/T14 | 引用打开确切版本和可验证位置；缺失位置明确提示；版本不可用不得跳最新版 |
| 结构 T10 | 模型伪造 ID/URL/页码不被采信；事实和推断有类型；政策不允许推断；渲染内容与验证内容相同 |
| 最终检查 T11 | 模型调用中撤权/删除/收紧配置，输出前复核阻断；Judge 不可用返回系统原因，不返回未验证结论 |
| 历史/多库 T12 | 客户端提交不能伪造可信答案；编号变化不串引用；旧消息不进入可信证据；受限正文/摘要不通过历史或缓存绕过 |
| 部署 T16 | 空库/存量迁移、重启、旧 worker 阻断、回滚、备份恢复有证据；安全门禁回滚不降级 |

以上范围内不得出现越权、跨库误删、删除复活。该验收限定于明确场景集，不表述为对所有未知场景的绝对安全保证。

## 模型效果评估

每个基础问题增加多种改写，按可回答/应拒答、政策/知识/混合、单库/多库、当前版/旧版/冲突版本分层。

指标包括：作答覆盖率、已作答正确率、事实结论支持率、推断合理性与标注完整率、引用支持准确率、定位准确率、无依据错误作答率、误拒答率、条件完整率、改写拒答一致性、Judge 对人工标签的一致性、P50/P95 时延和单问成本。

在独立校准集确定质量阈值，在保留测试集评估，记录样本量和分母；不能为得到通过结果而在同一测试集反复调阈值。阈值待基线后确认，不虚构达标数字。安全约束、Schema 和访问控制不依赖概率质量阈值。

## 异常与并发

覆盖对象写成功 SQL 回滚、Outbox 重复投递、构建中服务退出、Qdrant 部分写入、SQL 发布前退出、清理中退出、配置收紧、期限缩短/延长、两个管理员并发更新、下载期间撤权、模型与 Judge 超时/畸形输出。对每种异常保留恢复前后状态、资源清单和脱敏 trace。
