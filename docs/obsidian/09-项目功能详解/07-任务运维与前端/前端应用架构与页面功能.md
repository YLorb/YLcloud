# 前端应用架构与页面功能

## 产品目标

前端把个人文件、团队空间、RAG 知识库、知识画像和 AI 助手组织为连续工作流。用户需要清楚区分“文件已上传”“RAG 索引事务已完成”和“可选知识画像已完成”，并能从失败状态直接进入正确的恢复操作。

## 技术架构

- `main.tsx`：挂载 React，并注入 Query、会话、Tooltip 与通知 Provider。
- `App.tsx`：使用 React Router 定义公开路由、受保护路由、管理员守卫、错误边界和页面懒加载。
- `src/app/AppShell.tsx`：桌面可收起侧栏、移动抽屉、底部导航、主题、配额和账户操作。
- TanStack Query：持有服务端状态，负责缓存、失效、轮询和 mutation 反馈。
- React Hook Form + Zod：登录与配置表单验证。
- Radix UI：Dialog、Dropdown、Select、Switch、Tabs 和 Tooltip 的无障碍行为。
- Tailwind CSS 4 + CSS 语义变量：统一明暗主题、响应式断点和组件状态。
- Vitest + Testing Library：验证语义颜色及 RAG/画像任务重试路由。

## 状态与颜色语义

- 成功状态和主要确认操作使用绿色，同时显示图标与文字。
- 危险操作、失败和系统错误使用红色，并使用确认对话框或错误卡片。
- 等待使用橙色，运行使用蓝色，未知或关闭使用中性色。
- 颜色不是唯一信号；状态组件始终包含文本和图标。
- API 错误不伪装为空状态，页面保留原因和恢复按钮。

## RAG 与知识画像边界

知识库页面把“文档入库 → 解析 → 切分 → Embedding → 索引”定义为 RAG 核心事务。只有该事务完成后文档才可被展示为成功。知识画像是索引完成后的可选增强：关闭时跳过，开启时独立展示成功与失败文档数，不改变 RAG 事务成功语义。

## 响应式与无障碍

- 桌面侧栏支持真实收起，并为纯图标状态保留 `aria-label` 和 title。
- 移动端关闭的侧栏使用 `visibility: hidden`，避免屏幕阅读器聚焦不可见导航。
- 390px 登录页、文件页和底部导航已经过真实 Edge/Playwright 截图检查。
- 支持键盘焦点、跳到主要内容、减少动态效果和触控目标尺寸。

## 已闭环的页面问题

- AI Assistant 新建会话具有稳定草稿态，不会被历史会话初始化 Effect 覆盖。
- 文件页的分类入口请求服务端跨目录聚合；列表与网格共用多选与批量操作状态。
- Admin Settings 权限弹窗使用响应式 Grid，避免中文说明被选择框挤压成单字竖排。
- 后台任务行可点击打开详情，支持键盘访问、终态停止轮询和详情内重试。

TypeScript 严格构建和前端单元测试已通过，路由已经拆包。真实后端数据写入 E2E 必须在 Compose 重建并健康后执行；只有浏览器布局通过不能替代文件、Space、RAG、画像和任务重试的完整验收。
