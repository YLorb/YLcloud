# 保留期清理与会话删除级联
- 目标：落实 Retrieval Trace 7 天、Context Snapshot 15 天；删除会话时先通过墓碑和 Outbox 立即完成前端逻辑删除，再由后台任务幂等取消 Workflow 并物理删除两端全部会话关联数据；Workflow 运行审计按独立策略清理。
- 依赖：TASK-003/010。
- 产物：分批 cleanup job、dry-run/统计，会话删除墓碑、同事务清理 Outbox、前端不可见状态、后台取消与跨服务幂等清理、失败重试/告警、活跃 Run 保护、过期重建标记。
- 不包含：删除会话时删除独立长期记忆。
- 验收：边界时刻正确；running 不被定时清理；删除墓碑与 Outbox 在同一 Java 事务提交后接口幂等成功且前端立即隐藏；后台任务可从部分失败恢复并最终清除两端关联 Snapshot/Trace/Run 结果及运行数据；连续失败保持可重试并告警；迟到 callback/result 无法复活数据；长期记忆保留；重复删除安全成功。
- 风险/回滚：过度删除；dry-run、备份、分批和精确时间条件，启用前只预览。
- 回写：时区、边界定义、清理数量、恢复演练和会话删除证据。
