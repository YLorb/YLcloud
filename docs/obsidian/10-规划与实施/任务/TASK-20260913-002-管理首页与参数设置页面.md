# 管理首页与参数设置页面

## 目标与需求覆盖

完成 `/admin/dashboard` 与 `/admin/settings` 的前端原型，并把系统维护归入参数设置；消除指标、图表和设置标签占位。

## 前置依赖与输入

- 前置：TASK-20260913-001。
- 输入：Cloudreve 风格参考第 7、13、14 节，现有 Dashboard、SettingsPage 和旧 AdminSettingsPage 的字段/交互经验。
- 下游测试：[[10-规划与实施/测试/TEST-20260913-001-管理后台前端页面验收要求]]。

## 修改范围与预期产物

1. Dashboard 提供时间范围、四类指标、带图例的空趋势区、系统状态、最近活动和快捷入口。
2. Settings 提供站点、会话、验证码、增值服务、邮件、任务队列、服务器与维护横向标签。
3. 设置字段支持布尔、文本、数字、枚举、Secret 掩码、帮助说明、校验、脏状态、保存与放弃确认。
4. 服务器与维护标签包含维护状态、原因输入、启停确认和演示结果，不触发真实维护动作。
5. 默认空 Mock 下仍呈现完整设置结构；必要的默认值属于前端展示模型，不代表服务器配置。

## 明确不包含

- 真实统计、配置保存、Secret 读取、维护模式切换或设置热加载。
- 文件系统和存储策略配置，它们保留独立页面。

## 验收标准

- Dashboard 不再显示 `--` 或“图表区域”，空数据使用 0、空图和明确说明。
- Settings 每个标签都有字段布局或领域空状态，不出现“敬请期待”。
- 未保存修改在页面内可识别，离开/切换具有明确确认；刷新后全部重置。
- 维护动作始终标识为演示操作并进行二次确认。

## 测试、风险与回滚

- 测试：指标/空图、标签切换、字段校验、Secret 显隐、脏状态、离开确认、维护危险操作、窄屏标签滚动。
- 风险：展示默认值被误认为真实配置；页面必须常驻演示标识，字段说明注明未读取服务器。
- 回滚：恢复现有 Dashboard/SettingsPage；旧 AdminSettingsPage 和 API 保持不动。
- 实现 Agent/LLM 必须生成完整测试用例和独立测试记录，并回写状态与证据。
