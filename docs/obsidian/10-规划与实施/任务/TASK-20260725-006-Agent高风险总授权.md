# Agent 高风险总授权
- 目标/需求：用账号级 Web 授权和 Key 级高风险能力替换逐 Tool Grant；支持一次性和永久授权，动态覆盖 HIGH_RISK Tool。
- 依赖/输入：TASK-002；`WorkflowConfirmation*`、`WorkflowToolInvocationService/Registry`、V31。
- 修改范围/产物：新授权实体/API/UI契约；Gateway 统一校验；升级撤销全部旧 Grant；删除旧 Controller、Service、DTO、Mapper、Record、参数相似逻辑和旧表。
- 不包含：直接高风险 REST 授权。
- 验收：低风险按 Scope 自动执行；高风险无授权拒绝；一次性原子消费；永久授权撤销立即生效；未来 HIGH_RISK Tool 自动受控。
- 测试/通过：并发消费、跨用户/Key、直接 REST、降级绕过和旧数据迁移负例通过。
- 风险/回滚：授权面扩大；UI 强披露、审计并允许立即撤销；失败回滚并保持高风险全拒绝。
- 回写：V38 已新增账号/API Key 主体级高风险授权与内部调用 Key 绑定；Web 支持 `ALLOW_ONCE`（默认 5 分钟、最长 15 分钟）和 `PERSISTENT`，强制风险确认，保留消费/撤销历史。旧逐 Tool Controller、Service、DTO、Mapper、Record、参数相似逻辑及旧表已删除；真实 Gateway 并发消费、跨 Key、撤销、降级和旧入口负例见 [[10-规划与实施/测试/TEST-20260725-008-TASK-006-Agent高风险总授权测试记录]]。
