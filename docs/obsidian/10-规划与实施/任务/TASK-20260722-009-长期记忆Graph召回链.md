# 长期记忆与知识库 Graph 召回链
- 目标：由 Workflow 按任务判断知识需求，通过 Java Tool 同时编排长期记忆和知识库 Query、召回、RRF、Rerank、冲突/去重/安全及批量语义校验 Graph。
- 依赖：TASK-006/007/008。
- 产物：知识需求选择器、知识库范围决策、Query rewrite/independent query nodes，记忆/知识片段来源映射，候选预算，Rerank fail-closed，冲突胜出/清理调用，校验结果和实际使用知识库披露信息。
- 不包含：记忆写入工具内部实现和 Java 最终回答生成。
- 验收：与知识库无关的普通任务不召回文档；无显式选择时默认个人知识库，确有需要可从全部授权知识库自动补充最多 1–2 个并披露；显式选择后不得扩大范围；每次调用重新验证权限；所有待召回任务都有原问题+改写+独立 Query；去重不丢来源；新冲突记忆胜出；null/空/模型未加载返回 `NO_USABLE_MEMORY`；生产环境不得使用离线 Rerank fallback 冒充有效结果；候选不跨任务/用户混入。
- 风险/回滚：延迟和错误召回；分阶段预算、语义校验、shadow 对比，关闭长期召回可回滚。
- 回写：模型/Prompt/权重/阈值/预算及 Recall/MRR 证据。
