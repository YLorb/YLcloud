# Space 子树隔离与异步删除

## 目标与依赖

- 目标：用影响预览、不可撤销隔离和幂等统一任务替换同步递归删除。
- 前置：TASK-20260817-001/002、统一任务中心、现有 RAG/物理清理生命周期。
- 下游：[[10-规划与实施/测试/TEST-20260817-104-Space子树隔离与异步删除测试要求]]。

## 修改范围与产物

1. 新建 deletion batch、预览/确认 DTO/VO、Service、Mapper 和统一任务 Handler。
2. 预览返回目录/文件/知识数量、subtreeDigest、过期确认令牌；非空目录要求输入名称。
3. 确认时锁定并重算子树、权限、nodeVersion 和摘要；整树原子置 REMOVAL_PENDING，创建不可取消任务。
4. 所有列表、搜索、预览、下载、版本、RAG 和引用立即排除隔离节点。
5. Worker 迭代分页并按节点检查点清理 RAG、向量、配额、引用计数和最终物理对象；迟到结果校验 batch/version。
6. 完成置 REMOVED；失败保持隔离，管理员只能重试/修复，不能恢复 ACTIVE 或取消。
7. 删除旧 `SpaceFileService.removeTree` 同步递归路径及其直接外部副作用。

## 不包含

- 删除撤销、回收站、用户取消、失败自动恢复。

## 验收、测试与回滚

- 确认后立即不可见不可检索；重复任务不重复减引用或误删共享对象。
- Worker 崩溃、RabbitMQ 重投、Qdrant/MinIO 失败后可恢复收敛。
- 应用回滚不得恢复隔离节点；保留兼容 Worker 或停止发布而非降级数据。
- 实现者必须生成完整测试和独立记录；故障注入未通过不得发布。

## 实施记录（2026-08-17）

已实现影响预览、5 分钟确认快照、整树原子 `REMOVAL_PENDING`、不可取消统一任务、按深度逐节点独立事务清理以及文件/RAG 查询隔离。同步 Java 递归删除已移除。Java 全量测试通过；Qdrant/MinIO/RabbitMQ 故障注入和最终 `CONVERGED` 对账状态仍是发布前门禁，方案见 ADR 第 20 节。
