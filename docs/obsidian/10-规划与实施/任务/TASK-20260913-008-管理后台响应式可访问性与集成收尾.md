# 管理后台响应式、可访问性与集成收尾

## 目标与需求覆盖

把前述页面合并为一致、可导航、可构建和可验证的管理后台，完成响应式、深色模式、无障碍、路由和重复代码收尾。

## 前置依赖与输入

- 前置：TASK-20260913-002 至 TASK-20260913-007 全部完成；TASK-20260913-001 保持稳定。
- 输入：14 个页面、AdminLayout、App 路由、主题 Token 和测试要求。
- 下游测试：[[10-规划与实施/测试/TEST-20260913-001-管理后台前端页面验收要求]]。

## 修改范围与预期产物

1. 将 14 个路由全部切换到专属页面，移除管理路由对 PlaceholderPage 的依赖。
2. 统一侧栏、页面标题、演示提示、按钮顺序、筛选密度、表格、空状态、Toast 和危险确认。
3. 完成 320/768/1024/1440 响应式、移动导航、横向标签/表格滚动和详情面板适配。
4. 完成浅色/深色、reduced-motion、键盘顺序、焦点管理、可访问名称和颜色对比检查。
5. 增加管理页面级懒加载检查，清理重复/死代码；保留真实 API 与旧组件供后续适配迁移。
6. 汇总测试与截图证据，回写需求、ADR 和各任务状态。

## 明确不包含

- 真实 API 接入、后端测试、业务数据迁移或把原型状态升级为生产可用声明。

## 验收标准

- 14 个侧栏入口、刷新和直接 URL 访问均正常；无 PlaceholderPage、“敬请期待”、未实现按钮或不可达主操作。
- 全部页面持续标识演示模式，刷新后临时数据重置，无真实管理网络请求。
- 目标宽度、主题和键盘流程通过；弹窗关闭后焦点恢复，表格溢出限制在容器内。
- 前端测试、生产构建和浏览器 E2E 全部通过并有独立测试记录。
