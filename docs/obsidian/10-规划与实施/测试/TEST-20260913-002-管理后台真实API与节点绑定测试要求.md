# 管理后台真实 API 与节点绑定测试要求

## 门禁与执行责任

本文件仅定义测试范围和可判定标准，不代替实现 Agent/LLM 写完整用例或执行测试。每个 TASK-20260913-009 至 023 的实现者必须生成完整用例、执行并保存独立测试记录；记录含目标、内容、前置条件、测试数据、步骤、预期结果、实际结果、通过标准、证据和缺陷。实现完成但未验收只可标记 `pending-verification`。

## 通用必选范围

1. 单元：DTO/VO 映射、状态转换、权限判断、错误归一、计数口径和任务 checkpoint/归档规则。
2. 回归：14 个管理路由、普通用户 `/files`、`/spaces`、`/tasks` 及原站点设置、权限组、审计、备份 API 不回退。
3. 异常/边界：空结果与故障区分、未知枚举、分页上限、时间范围、重复提交、并发冲突、过期数据、节点离线、数据库/消息队列/对象存储失败。
4. 安全：未登录/USER/ADMIN 矩阵、管理员免逐资源授权的仅管理路径范围、脱敏、审计、节点配对防重放/SSRF、危险操作确认；不得把 JWT/密钥/文件正文写入事件或测试输出。
5. 本阶段新增跨模块 API 和迁移，必须执行数据库集成、前后端契约集成和关键浏览器 E2E；节点使用受控无 Web 从机或协议级测试替身证明真实配对，Mock 遥测不算证据。
