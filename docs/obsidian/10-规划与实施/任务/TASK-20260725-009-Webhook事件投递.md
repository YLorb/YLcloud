# Webhook 事件投递
- 目标/需求：提供文件、知识、Agent 和 Space 事件订阅，至少一次投递、签名、重试、事件幂等及可选正文。
- 依赖/输入：TASK-007/008；业务 Outbox、站点设置。
- 修改范围/产物：订阅/事件/Delivery 表、签名 Secret、投递 Worker、退避与死信、SSRF 策略和管理 UI 契约。
- 不包含：跨资源全局有序和恰好一次。
- 验收：唯一 `eventId`、版本、时间戳齐全；正文受 Scope 控制；每次解析/重定向检查目标 IP；内网仅所有者显式开放。
- 测试/通过：重复、乱序、超时、签名轮换、DNS rebinding、重定向和跨用户泄漏测试通过。
- 风险/回滚：SSRF/数据外泄；默认禁用内网与正文最小化；紧急停用投递 Worker。
- 回写：记录事件目录、重试策略和安全测试。
