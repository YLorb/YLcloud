# Share-link 验收要求

适用 TASK-20260920-001 至 009。本文只有测试范围和可判定标准，未生成完整测试用例、未执行测试，不是测试结果。

| 验收组 | 范围 | 通过标准 |
|---|---|---|
| V01 数据与迁移 | 空库/旧库、主键回填、短码字符大小写、未知码日志、迁移失败 | 新结构可用且不破坏文件；A/a 不合并；失败记录无可访问残留；旧记录清理在切换阶段。 |
| V02 短码 | 小/长 ID、右补 a、截前8、拼接/补位碰撞 | 严格沿用字符表，恒定8位；冲突一次失败不重试、绝不返回他人链接；不反解码定位。 |
| V03 创建与复用 | 同人同目标、不同创建者、同 UUID 不同归属、并发、已过期/耗尽 | 仅有效归属记录可复用；同人并发不重复创建；过期或耗尽新 ID；他人不能管理。 |
| V04 条件修改 | 默认无限/永久、固定时长、自定义时刻、延期、撤销、上限降低、并发修改 | 累计次数不重置、地址不变；原期限累加，过期/永久从当前计算；超限立即失效；版本冲突不丢修改。 |
| V05 权限生命周期 | 个人/空间可编辑与只读、他人节点、删除/恢复、失权/恢复、替换后回退 UUID | 按真实编辑能力授权；恢复需其他条件有效；替换永久失效，不因 UUID 还原复活；admin 管理不绕过下载源授权。 |
| V06 密码 | 空值、Unicode/长密码、错误、重新打开、条件修改、强制下载互斥 | 开启非空、无复杂度和静默截断；哈希不外泄；刷新需重输；旧凭据不可绕过密码更新；前后端均拒绝互斥条件。 |
| V07 下载批准 | 单次、多次、同人、快速点击、最后1次并发、断流、HEAD | 按实际批准数计次；剩余1次只成功批准1次；批准后失败不退款；HEAD/open不扣；不添加一期去重限制。 |
| V08 文件夹 | 无预览/目录、ZIP整体下载、空目录、增删、替换、新加入后替换、跨目录移动 | 页面只见文件夹；ZIP一次计次；新增进入下次ZIP、删除排除、替换项排除；不能访问源目录之外数据。 |
| V09 传输安全与资源 | ZIP重名/中文/路径、断连、MinIO失败、大于可用堆内存的总数据、并发 | 有效ZIP路径且无穿越；不整文件Blob缓存；内存不随总字节线性增长；中断不伪报成功；保存资源与吞吐观察值，不虚构目标。 |
| V10 公开页面 | 匿名/登录、卡片、强制下载、复制、无效码、旧URL和旧API | 当前origin+/s/8位；强制无卡片；所有失效HTTP200精确文案；旧preview/stream/download无文件泄露。 |
| V11 日志与管理 | 有/无登录、无效Token、密码错误、未知短码、普通用户越权 | 每次页面打开记录；可信登录账号或匿名IP、时间、城市“-”；只有admin能读取；普通用户只见自己链接次数。 |
| V12 保留期 | 30天前/边界内记录、时区、分批、失败重跑 | 仅清理截止之前记录；不误删新记录；重跑安全；累计下载次数不受影响。 |
| V13 回归与发布 | 个人/空间正常下载预览、角色、管理员、存储、旧表清理、回滚 | 正常登录功能无回归；清理有备份证据；回滚不复活旧分享；真实API无Mock替代。 |

## 必选执行层次

- 单元、回归、异常边界、安全：每个具体功能必须覆盖。
- MySQL/对象存储/认证/迁移集成：001–005、008–009 必须。
- 浏览器端到端：创建→复制→匿名/登录访问→下载→修改→撤销及管理员日志；006–009 必须。
- 并发：最后额度、创建复用、条件修改与批准竞争；003、005 必须。
- 性能与容量：大文件与ZIP内存、存储流中失败；005、009 必须。无预定吞吐SLA，记录环境及限制。
- 兼容：实际部署MySQL、Java17、Windows文件名与部署环境、目标浏览器；迁移及下载链路必须验证。
