# TASK-008 版本化开放 API 测试记录

## 测试目标

验证 `/api/v1` 固定版本开放 API、`/api/open` 最新版别名、API Key 专用认证、统一元数据/错误/分页、写操作幂等和版本只读切换；确认管理员与部署运维能力未进入开放契约。

## 接口清单

| 能力 | 接口 |
|---|---|
| 能力快照 | `GET /capabilities` |
| 文件 | `GET /files`、`POST /files/upload`、`POST /files/folders`、`PUT /files/{fileId}/move`、`DELETE /files/{fileId}` |
| Space/知识 | `GET /spaces`、`POST /spaces/{spaceId}/knowledge/query` |
| Assistant | `POST /assistant/sessions`、`POST /assistant/sessions/{sessionId}/queries` |
| Agent | `POST /agent/sessions/{sessionId}/queries` |

表内路径同时挂载在 `/api/v1` 和 `/api/open`。文件删除只进入可恢复回收站；契约不含管理员、部署运维、永久删除、分享和成员管理接口。

## 契约与状态码

- 成功响应统一为 `data + meta`，元数据包含 traceId、当前版本、最新版本和是否命中无版本别名。
- 错误响应统一为 `error + meta`；认证失败 401、Scope/资源边界失败 403、缺失/非法参数与非法 JSON 400、冲突 409、旧版本只读 410、上传过大 413。
- 响应头包含 `X-Trace-Id`、`X-API-Version: v1` 和 `X-API-Latest-Version: v1`；`/api/open` 额外返回 RFC 语义的 299 Warning。
- 分页从 1 开始，返回 page、pageSize、total、hasMore；站点设置限制最大 pageSize。
- 文件上传、目录创建及 Assistant/Agent 查询要求 `Idempotency-Key`；目录创建已接入跨存储幂等账本，完成后按原结果回放。
- Agent 查询会用认证上下文覆盖客户端提供的 Key 标识，并将真实 `apiKeyId` 纳入 Workflow 权限快照与上下文哈希，供 Tool Gateway 执行 Key 级高风险授权。
