# 版本化开放 API
- 目标/需求：以 `/api/v1` 覆盖普通用户文件、Space、知识、Assistant 和 Agent 核心能力；无版本路径走最新版；旧版本30天后只读。
- 依赖/输入：TASK-007；现有 Controllers/DTO/VO、`WebConfig`。
- 修改范围/产物：版本化门面、统一错误/分页/幂等契约、版本策略设置、只读门禁和 OpenAPI 文档。
- 不包含：管理员与部署运维 API；第二个真实主版本。
- 验收：v1 同主版本兼容；无版本行为有明确响应头；过渡期结束所有副作用请求拒绝、读取继续；生产客户端可固定版本。
- 测试/通过：契约、兼容、认证、幂等、大小限制和端到端测试通过。
- 风险/回滚：双路由漂移；版本门面复用同一业务服务并执行契约快照。
- 回写：记录接口清单、状态码和兼容测试结果。
