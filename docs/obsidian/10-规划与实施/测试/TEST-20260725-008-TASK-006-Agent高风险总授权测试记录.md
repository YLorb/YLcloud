# TASK-006 Agent 高风险总授权测试记录

## 测试目标

验证账号级 Web 授权和 API Key 级高风险能力替代旧逐 Tool/参数 Grant；所有当前及未来 `HIGH` Tool 由 Gateway 动态统一校验，一次性授权原子消费，持久授权撤销立即生效，且不能授权高风险 REST。

## 权限矩阵

| 调用主体 | Tool 风险 | 主体授权 | 结果 |
|---|---|---|---|
| Web 账号 | READ_ONLY/WRITE | 无 | 通过服务 JWT Scope 后自动执行，业务资源仍实时鉴权 |
| Web 账号 | HIGH | 无/过期/撤销 | 403 拒绝 |
| Web 账号 | HIGH | ALLOW_ONCE | 仅一个 invocation 原子消费成功 |
| Web 账号 | HIGH | PERSISTENT | 有效期内允许，撤销后后续调用立即拒绝 |
| API Key | HIGH | 仅账号 Web 授权 | 403 拒绝，不能借用账号授权 |
| API Key | HIGH | 本 Key 授权 | 仅 Gateway Tool 可消费；不接入普通 REST 鉴权链 |
| 任意主体 | HIGH Tool 伪报 WRITE | 任意 | Registry 风险等级不匹配，409 拒绝 |

## 真实 Gateway 风险测试

| 场景 | 结果 | 结论 |
|---|---|---|
| 未授权调用 `smtp.send_email` | HTTP 403 | 高风险默认拒绝 |
| ALLOW_ONCE 两请求并发消费 | 一个 200/SUCCEEDED，一个 403/REJECTED | 行锁和条件更新保证仅消费一次 |
| 一次性授权消费后新 invocation | HTTP 403 | 不可复用 |
| PERSISTENT Web 调用 | 200/SUCCEEDED | 持久授权有效 |
| 携带 `apiKeyId=999` 借用 Web 授权 | HTTP 403 | 账号/Key 主体隔离 |
| 撤销 PERSISTENT 后新 invocation | HTTP 403 | 撤销立即生效 |
| 客户端把 HIGH Tool 声明为 WRITE | 专项测试 409 | 无法通过降级绕过 |
| 调用旧确认入口 | 非成功响应，且源码无旧 Controller | 旧模型不可用 |
