## 当前一句话总结

Mini AI Workflow Builder 是一个用 Python 实现的轻量 Agent 工作流平台。它先实现确定性的 Workflow Engine，再逐步加入模板选择、真实 LLM 接入和后续 Goal 生成 Workflow 的能力。

## 当前阶段

项目已经完成：

- Level 1：执行人工定义的 Workflow。
- Level 2B：规则从模板库选择 Workflow，并交给 Level 1 Engine 执行。
- DeepSeek OpenAI 兼容 API 接入。
- CLI run / select 入口。
- 自动化测试与定量 benchmark。

仍未完成：

- Graph Workflow 稳定版的数据流校验、安全预算与运行语义收口。
- Markdown Workflow Importer。
- Tool Schema / 权限 / 风险检查。
- 真实 MCP Client Provider。
- Level 3：AI 根据 Goal 生成 Workflow。
