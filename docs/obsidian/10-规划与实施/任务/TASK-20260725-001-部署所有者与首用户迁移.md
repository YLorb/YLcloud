# 部署所有者与首用户迁移
- 目标/需求：实现唯一、不可转移的部署所有者；空实例首个普通注册者成为所有者；已有实例选择最小 `user_id` 并恢复启用。
- 依赖/输入：REQ-20260725-001；现有 `user_registration_guard`、`SignService`、`User`。
- 修改范围/产物：Flyway 所有者字段与唯一约束；事务化首注册/历史迁移；所有者禁止停用、降级、删除；删除 `BootstrapAdminInitializer` 及其配置、测试与文档入口。
- 不包含：普通管理员资源授权、账号注销清理。
- 验收：并发首注册只产生一个所有者；迁移可重复验证；所有者约束后端强制；每个用户仍恰有一个 PERSONAL Space。
- 测试/通过：单元、MySQL 集成、并发、历史数据和安全负例全部通过。
- 风险/回滚：身份选错不可接受；升级前备份，迁移事务失败即中止，回滚镜像并恢复备份。
- 回写：记录迁移版本、受影响账号、测试证据和状态。
- 测试：[[10-规划与实施/测试/TEST-20260725-001-统一知识平台实施测试要求]]

## 实施回写

- Flyway 版本：`V32__deployment_owner_and_first_user.sql`。
- `users.deployment_owner` 由数据库唯一槽位和 CHECK 约束保证全实例最多一个、必须为启用 ADMIN。
- 空实例注册通过 `user_registration_guard` 行锁串行化；行锁被调整为事务内第一次数据库读取，避免 MySQL `REPEATABLE READ` 在等待锁前建立旧快照。
- 历史实例将最小 `user_id` 恢复为启用 ADMIN 并标记为部署所有者。
- 后端拒绝部署所有者的停用和降级；后续账号删除实现必须复用同一所有者保护。
- 已删除 `BootstrapAdminInitializer`、Bootstrap 管理员环境变量、部署检查、测试和文档入口。
- 修复服务 JWT 发行器/验证器多构造器的 Spring 注入声明，使真实应用验收可启动。

## 验收结果

- Win10 身份下的 Docker MySQL 8.3 空库迁移和 V31 历史库升级均成功。
- 历史数据：`user_id=2` 被恢复为唯一启用 ADMIN 所有者；`user_id=5` 保持普通管理员。
- 数据库负例：第二所有者、停用所有者、降级所有者均被唯一/CHECK 约束拒绝。
- 两个并发首次注册请求均返回 200；最终仅首用户为所有者，两个用户各有一个 PERSONAL Space。
- 后端专项测试 9/9、全量测试 163/163 通过，后端打包和前端生产构建通过。
