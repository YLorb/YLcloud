# 单 Run 就绪节点并行调度
- 目标：将单 Run 从顺序拓扑执行扩展为有界 Ready Queue，无依赖节点最多 3 并行。
- 依赖：TASK-002/003/007。
- 产物：Ready scheduler、节点 State Patch、稳定 nodeId commit、确定性 Merge、并发取消/超时/预算。
- 不包含：跨机分布式队列和嵌套 Workflow。
- 验收：共享 Context 不被并发节点直接修改；同名 patch 冲突确定失败；完成顺序不改变结果；并发上限不可由 Workflow 提高。
- 风险/回滚：时序/迟到结果污染；用 invocation/execution 门禁，feature flag 可切回顺序 Executor。
- 回写：状态转换表、竞争证据、并行增益和已知限制。
