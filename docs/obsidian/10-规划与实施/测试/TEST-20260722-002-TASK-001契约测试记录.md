## 正确性审查

- Workflow Result 没有 `finalAnswer` 字段，未知字段被 Schema、Pydantic 和 Jackson 拒绝。
- `requestContextHash` 与 `snapshotHash` 分字段保存，并验证 Result 与 Snapshot Draft 一致。
- Run 最多 6 个业务节点、最多 3 个并行节点；并行预算不能超过业务节点预算。
- `CANCELLED`、`TIMED_OUT` 和 `ABANDONED` 均映射 Java `FAILED`；`DEGRADED` 映射 `SUCCESS + degraded=true`。
- 显式选择知识库时不能自动补充；自动补充最多两个且不能与已选范围重叠。

## 安全审查

- HIGH 风险 Tool 无确认时拒绝；确认必须绑定同一 user/tool，授权时间必须带时区且结束晚于开始。
- `ALLOW_ONCE` 不能携带类似命令范围；Tool 成功结果与失败错误互斥。
- Schema 同步器只处理固定白名单文件，拒绝符号链接；检查模式不创建目录、不写磁盘。
- Retrieval Trace 只允许引用、Hash、Query、分数、排序和淘汰原因，不包含候选正文。
- 测试和实现未写入 API Key、JWT、数据库密码或真实外部账号。
