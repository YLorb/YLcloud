# 管理后台真实 API 接入与节点绑定

## 背景与原始诉求

REQ-20260913-001 已定义 14 个 `/admin` 前端原型。本需求将已有后端能力接入对应页面，并对用户明确点名的缺口补建真实 API。2026-09-13 用户确认：存储策略的精确方案暂缓；节点是无 Web 界面的同版本 YLcloud 从机，本轮只做真实绑定/通信测试，监控与跨机文件数据使用明确标注的 Mock；ADMIN 可不再取得逐资源授权而查看全站数据，已知晓权限扩张风险。

下游方案：[[10-规划与实施/ADR-20260913-002-管理后台真实API接入与节点控制面方案]]。

## 用户与场景

- 操作者：ADMIN。管理员浏览站点/用户/权限/文件/任务/审计/备份/事件/统计，按真实 API 授权执行受支持命令。
- 节点绑定：管理员提供无 Web 从机的内部地址和配对凭据；服务器完成身份、版本、连通测试后持久化绑定；解绑只断开控制关系，不删除 MySQL 元数据或从机上的实体。
- 失败场景：服务不可达、过期绑定、存储不通、跨用户引用冲突、任务处理中断、归档后查询、事件写入失败及指标统计延迟。

## 本轮必须完成

1. 接入现有站点设置、维护模式、管理员全文搜索、备份与恢复验证查询、安全审计/留存、用户与权限组、组配额的真实接口；只呈现后端实际支持的字段和动作。
2. 新增 MySQL 权威数据驱动的全站文件查询，个人/Space 分视图；管理员解除选定引用，遵循已有回收站、Space 删除和引用计数/物理清理链路，不直接删除共享 Blob。
3. 新增全站统一任务查询、允许的重试/取消、逻辑归档；增量建立持久化任务步骤 checkpoint 与人工续跑机制。所有任务可见，具体命令以状态与处理器能力为准。
4. 新增系统事件：登录、文件上传/下载、任务开始/终止/完成等成功与失败事件，脱敏、按 30 天留存；安全审计仍单列，不用新事件替代既有审计。
5. 新增 MySQL 按日指标：新增文件引用、新增 Blob、新用户、新 Space；前端按日期范围展示，有数据缺失与查询失败的区别。
6. 新增节点配对、通信测试、绑定、解绑的真实控制面与管理页适配；节点性能、容量、跨机文件读写和真实维护调度保持 Mock/不可操作提示。
7. 前端按真实能力逐域切换，不再对真实数据执行纯内存“成功”命令；无对应 API 的字段/按钮禁用或空态。

## 非目标与明确延期

- 存储策略 CRUD、策略选址/迁移、Cloudflare R2/另一套 MinIO 数据面、跨节点实际文件读写与多机真实调度：等待独立方案；不得用当前节点绑定冒充已具备存储能力。
- Token 消耗统计：等待完整 token 计量设计；首页显示“暂未接入”，不填 0。
- 分享治理、订单、滥用举报、OAuth 及设置页无后端键的业务字段：不补建 API，保留结构和不可用说明。
- 普通用户文件/任务 API 的权限语义不能因管理页接入被隐式改变。

## 验收标准

1. 真实能力显示真实来源、加载/空/失败状态和实际命令结果；不再出现“演示保存成功”却未持久化。
2. 全站文件查询只依据 MySQL 授权元数据；个人和 Space 可切换，分页稳定；解除某条引用后其他引用和 Blob 保持正确。
3. ADMIN 的全站操作由服务端角色校验、二次确认和审计保护；普通用户仍不能越权。
4. 所有统一任务可查；归档不物理删除；仅可恢复且已有持久 checkpoint 的任务允许人工续跑，重复命令不产生双执行。
5. 系统事件成功/失败均可查，30 天到期清理，载荷不含密钥、文件内容、JWT 等；安全审计不回退。
6. 新增引用/Blob/用户/Space 按 MySQL 创建时间与明确时区按日统计；秒传时引用和 Blob 数可不同；Token 不伪造。
7. 节点在配对与真实通信测试通过后才成为已绑定；解绑保留元数据；跨机能力和 Mock 指标始终明确标示非真实。
8. 实现 Agent 必须补充完整用例、执行单元/回归/异常/安全/跨模块集成及关键浏览器链路测试，生成独立测试记录；未验证仅为 pending-verification。

## 约束、风险与决策记录

- 2026-09-13 用户确认 ADMIN 免逐资源授权。这改变既有 `AdminResourceAccessController` 的保护边界；一名 ADMIN 失陷即可读取全站数据，需作为显式接受风险保留审计、会话安全、敏感操作确认和最小返回字段。
- 2026-09-13 用户确认节点解绑后 MySQL 记录保留，相关文件访问失败而非永久删除；本轮不部署真实跨机数据面。
- 2026-09-13 用户明确存储策略与 Token 计量延期。该延期是本需求的已接受边界，不作为未决事项阻断其他域实施。
- `checkpoint()` 现有实现只检查取消与租约，不提供可恢复步骤；后续必须新增持久化协议，不得在原型状态中宣称“可恢复”。
- 未决事项：本轮范围内无阻断项。具体节点地址白名单、心跳周期、分页上限和事件字段可在实现任务中依据部署配置确定并通过安全测试验证，不扩大业务范围。
