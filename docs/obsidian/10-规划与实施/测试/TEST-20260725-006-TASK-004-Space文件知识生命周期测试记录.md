|---|---|---|
| Space 文件首次上传 | `INDEX_PENDING/version=1/searchable=false` | 入库即知识化且未提交索引前不可检索 |
| 重复上传幂等键 | 两次返回同一文件 ID | 通过 |

| 立即移除待索引文件 | `REMOVAL_PENDING/version=2/searchable=0` | 先封锁检索再异步清理 |
| 被移除文件旧索引事件 | `DONE/SUPERSEDED_BY_REMOVAL` | 不会复活已移除资源 |
| 被移除文件派生引用 | `space_rag_chunk_ref=0`、文档禁用 | 该 Space 派生物已隔离 |
| 清理故障 | 移除事件 `FAILED` 且保留错误 | 可追踪、可重试 |
| 仍有两个业务引用 | `file_info.count=2`，无物理清理任务 | 仅零引用才允许物理清理 |
