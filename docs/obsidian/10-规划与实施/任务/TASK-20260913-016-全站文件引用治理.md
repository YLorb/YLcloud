# 全站文件引用治理

- 目标：以 MySQL 的 `user_file`/`space_file` 为权威来源提供全站文件查询，管理员只解除选定引用，个人/Space 在 UI 分视图。
- 前置与输入：TASK-20260913-009；`AdminResourceAccessController`、文件/Space 领域服务、`file_info` 引用计数及已有删除/回收站流程。
- 产物：有稳定分页/筛选的 `/api/admin/files` 查询与详情、经 MySQL 引用定位的预览/下载、按引用类型定位的解除引用命令、审计与前端适配；既有 `AdminResourceAccessController` 的管理员跨用户读取也同步改为只校验 ADMIN，普通用户 API 不变。
- 不包含：扫描对象存储列文件、直接删除共享 Blob、存储策略或跨机文件操作。
- 验收：个人与 Space 数据正确隔离；同 Blob 多引用时仅目标引用变化，最后引用才按既有清理流程；重试幂等、无权限被拒绝、页面准确显示失败。
- 测试：共享引用、回收站/Space 特殊状态、预览/下载流、并发删除、最后引用、物理清理失败、ADMIN/USER 权限、审计和 E2E；通过才完成。
- 风险与回滚：ADMIN 可见全站隐私为用户接受风险；最小字段、审计、确认与限流。数据变更不可通过 UI 回滚，应依既有恢复流程，发布前正式库备份。
