# 账号注销、删除与数据导出
- 目标/需求：注销立即封禁，默认3天由 ADMIN 恢复；到期扫描提交异步删除；支持异步加密导出。
- 依赖/输入：TASK-002/003/004/007/017/018/019；统一任务中心、清理 Outbox、会话和记忆服务。注销删除必须复用已迁移的 cleanup、memory、chat/workflow 取消与资源版本栅栏。
- 修改范围/产物：账号状态机、恢复 API、删除编排步骤、导出清单/加密/下载期限；TEAM OWNER 前置校验。
- 不包含：部署所有者注销；TEAM 中仍被引用数据删除。
- 验收：注销用户不能自恢复或正常登录；任务可重入；个人数据按清单清除；团队引用保留；导出不含 Key 明文/Secret/他人数据。
- 测试/通过：时间边界、恢复竞态、部分失败、迟到回调、跨存储删除、统一任务取消/旧 Worker 晚写拒绝和导出安全通过。
- 风险/回滚：不可逆误删；恢复期、状态锁和备份前置；进入 PURGING 后仅通过备份灾难恢复。
- 回写：记录数据清单、每步证据和残留对账。
- 测试：[[10-规划与实施/测试/TEST-20260725-001-统一知识平台实施测试要求]]

## 实施内容

### 数据库迁移 (V48)
- `users` 表增加 `account_status`、`cancelled_at`、`cancel_requested_by`、`recoverable_until`、`purging_started_at`、`purged_at` 字段
- 新建 `account_deletion_job` 表：异步删除任务编排
- 新建 `data_export_job` 表：加密数据导出任务
- 新建 `account_recovery_log` 表：恢复操作审计日志

### 后端实现
- `AccountLifecycleService`：注销请求、ADMIN 恢复、状态查询、过期扫描
- `AccountDeletionOrchestrationService`：可重入删除编排（取消会话→清理记忆→清理文件→清理向量→吊销API Key→删除Webhook→标记PURGED）
- `DataExportService`：AES-256-GCM 加密导出，限时下载链接
- `AccountLifecycleController`：REST API (`/api/account/*`)
- `AccountLifecycleTaskHandlers`：统一任务处理器（ACCOUNT_DELETION、DATA_EXPORT）
- `AccountLifecycleScheduler`：定时扫描过期注销账号

### 安全增强
- `JwtTokenInterceptor`：拦截非 ACTIVE 状态账号
- `LoginService`：登录时检查账号生命周期状态
- 部署所有者禁止注销
- TEAM OWNER 前置校验（必须先转让或解散团队）

### 测试结果
- 后端全量 283 项测试通过
- 编译成功，无错误
